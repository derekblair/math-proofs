# Erdős–Straus identities and obstructions

The following describes the scope of the Lean formalization related to the following accompanying paper(s):

- [An Erdős–Straus Covering Identity for n ≡ 217 (mod 264)](../../preprints/erdos-straus-identity-217mod264-October-3-2026/paper.pdf) *(historical PDF; see [corrected source](../../preprints/erdos-straus-identity-217mod264-October-3-2026/build/main.tex))*
- [CRT Escape from Local Quadratic Obstructions on Square Classes Modulo 840](../../preprints/erdos-straus-finite-identity-barrier-October-4-2026/paper.pdf) *(historical PDF; see [corrected source](../../preprints/erdos-straus-finite-identity-barrier-October-4-2026/build/main.tex))*

## Scope

### ES-001: Covering identity for `n ≡ 217 (mod 264)` (`[PROVED]`)

`Mathproofs/NumberTheory/ESIdentity.lean` proves `es_covering_217mod264`: for every natural number `n ≡ 217 (mod 264)`, there exist positive natural denominators `x, y, z` satisfying `4x = n + 3`, `y = n(n + 3)`, `11z = n(n + 3)`, and `4/n = 1/x + 1/y + 1/z`. The compatible rational-equality lemma remains available as `es_identity_217mod264`, and the example `n = 1009` is included.

`Mathproofs/NumberTheory/ESIdentityCRT.lean` proves `covered_classes_exact`, `parent_fiber_card`, `covered_parent_fiber_card`, and `covered_class_identity`: the exact six covered subclasses modulo 9240, positive covering witnesses for their members, and the exact one-out-of-eleven residue count per parent class modulo 840.

All statements use only standard Lean axioms (`propext`, `Classical.choice`, `Quot.sound`). The former novelty claim is withdrawn in light of Miguel Angel Lopez (2024), arXiv:2206.10319v4; search counts (`12,827` candidates, `3,862` prime-covering), prime-density theorems, and priority claims remain unformalized.

### ES-002: CRT escape from local quadratic obstructions (`[PROVED]` conditional kernel)

`Mathproofs/NumberTheory/ESBarrier.lean` proves `es_crt_escape`: given finitely many progressions `Aᵢ t + Bᵢ` with `8 ∣ Aᵢ` where each `Bᵢ` either is a nonsquare modulo some odd prime `q ∣ Aᵢ` or satisfies `Bᵢ ≢ 1 (mod 8)`, infinitely many primes in each of the six listed square classes `{1, 121, 169, 289, 361, 529} (mod 840)` avoid every progression. The proof uses CRT and Mathlib's proved general Dirichlet theorem with no custom axioms (the former inconsistent `schinzel_mordell` and `dirichlet_arith_prog` axioms and false rational-polynomial `es_barrier` statement were removed on October 23, 2026).

The Schinzel–Mordell implication from integer polynomial identities to the supplied local quadratic obstructions remains unformalized; the full polynomial-identity barrier is not claimed as a Lean theorem.
