# Ore-type Bondy on cographs: a longest-cycle separator theorem

Let G be a finite simple connected cograph with a cycle, and let k ≥ 2. The following are equivalent:

1. Some cycle leaves no k-vertex path outside it.
2. Every longest cycle leaves no k-vertex path outside it.
3. There is no nonempty vertex set S for which G−S has at least |S|+1 connected components each containing a k-vertex path.

More strongly, a longest cycle that leaves a k-vertex path produces such a cut contained in the cycle. Consequently, if G is k-connected and σ_{k+1}≥n+k(k−1), then every longest cycle leaves no path of order k. This proves the cograph case, not the unrestricted conjecture. Here σ_{k+1} is the minimum degree sum of an independent (k+1)-set, or +∞ if no such set exists. The criterion is in terms of paths, not merely component orders.


## Join identities
For a graph A, let π(A) be the minimum number of paths that partition its vertices (π(empty)=0). For a disjoint union it is additive. For a complete join J of nonempty child vertex sets A_i, π(J)≤t (t≥1) iff each π(A_i)≤ t+Σ_{j≠i}|A_j|. If at least two children are nonempty and |J|≥3, J has a Hamilton cycle iff each π(A_i)≤Σ_{j≠i}|A_j|. Necessity by deleting the other children from the paths or cycle.

To prove sufficiency, choose a minimal path cover in each child, and regard each path as one token of its color. Splitting paths at edges allows color i to have any count in [π(A_i), |A_i|]. For a cycle require each token count ≤ the total of the other colors. If the initial counts violate this, there is exactly one dominant color; keep its token count and monotonically add other tokens until their total equals it, possible by the assumed bound. Others cannot become dominant because each count is then at most the dominant count. A circular arrangement with no equal adjacent colors exists: place the largest color's tokens separated by slots; take all other tokens grouped by color and assign them round-robin to slots. Each slot receives at least one token and no repeated color. Expand tokens into paths and connect consecutive endpoints across child colors. If there are only two real tokens then total order ≥3 ensures the two closing connections are distinct. For t-path sufficiency use t dummy singleton tokens of one additional color, then delete them from the circular arrangement. If the initial total real tokens ≤t we are already done. Otherwise dummy cannot dominate and may be treated as fixed. If a real color dominates, bring the other counts including dummies up to its count exactly as before (the assumed bound includes t). This proves the identities, allowing unoccupied children to be omitted.

## Decomposition of a marked longest cycle
Let X be the vertex set of a longest cycle and let P be a k-vertex path disjoint from X. Write a union–join cotree, with each connected nontrivial node a join and each disconnected node a union; singleton leaves allowed. The root, since connected and |X|≥3, is a join. For a node U write X_U=X∩U and π_U=π(G[X_U]). X meets at least two children at root: otherwise inserting an arbitrary vertex of another child into an existing cycle edge would grow X's cycle.

At root the cycle inequalities are π_i≤u_i, where u_i=Σ_{j≠i}|X_j|. If some unused vertex lies in child i then π_i=u_i (adding it in its own child costs at most one extra path as a singleton; all other bounds relax). If two different children have unused vertices, both are tight. Then adding one to each increases each own path demand by at most one, but also increases its opposite capacity by one (and relaxes the others), contradiction. Therefore all unused vertices lie in a unique child i, which is tight. Delete all other root children into S (retained as unchanged selected vertices for later comparison); the retained child has π_i equal to the number u_i of these vertices. P is in that child.

More generally at every retained node U below the root X_U is maximum order among subsets coverable by at most π_U paths, conditional on all other selected choices. If improving its size while not increasing π_U, all inequalities in each ancestor join remain valid: its own demand does not increase and the size increase relaxes others; at union demands add. At ancestor path-cover nodes the same comparison propagates up, and at root gives a bigger cycle. We only need this argument for nodes on the recursion, whose ancestors were already expanded. Empty X_U is allowed; a node with selected graph cover demand 0 cannot increase order at demand 0.

Expand union nodes through each connected child and maintain sum of child demands. Independently recognize that P is confined to one child of any retained union node containing it. For a retained connected node U with X_U nonempty and t=π_U, if t=1 and U does not contain P, leave it as a terminal; its selected set is traceable, not necessarily its whole original graph. An untouched connected node is also terminal. Otherwise expand its join (a singleton cannot qualify). If X_U≠U, any child with unused vertex must have π_i=t+u_i, by the same one-vertex augmentation argument at fixed t. There cannot be two tight children when t≥1, since each such condition implies |X_i|≥|X_j|+t for the other tight child. Hence all other children have been used fully. If X_U=U and t≥2, the minimality of t gives equality π_i=t+u_i for some child by the join identities, and again the child is unique. In either case delete all other join children into S and retain the unique dominating child. If U contained P, then X_U≠U and P remains in the retained child. Continue. At a join with a partial X_U, this argument also covers a hypothetical empty selected child: if it is deficient it would need π_i≥t≥1, impossible. If P visits a join whose X_U empty, stop there as an unused terminal; P remains wholly inside.

The terminals are exactly the connected components of G−S: only disjoint unions were branched, while in joins all but one child were deleted. Telescope the selected demands through union sums and join equations π_i=t+u_i; at root t=0. Thus the number of selected terminals, each π=1, equals |S|. All unused terminals have π=0. One contains P. At least one selected terminal exists since root added a nonempty set of opposite-child vertices to S and gives positive initial demand. Therefore S is a vertex cut and |S|≥k. Locally the same telescoping identity implies that every retained node with demand t has at least t selected terminals below it.

## Every selected terminal contains at least k selected vertices
Suppose a selected terminal D has q=|X_D|<k. Remove those q selected vertices and insert the k vertices of P from the unused terminal. All discarded/hub children retain their original selected versions (they were full). In the decomposition tree the least common ancestor of these two terminals is a union node: every expanded join retains only one child.

On the donor-only route below that union, the demand drops by at least one at the terminal and propagates upward. At unions this is additive. At an expanded donor-only join its original demand t≥2 by the rule (it is not on the P route), its retained child has π=t+u with u the sum of sizes of its other children. Inductively the child's demand drops to ≤t+u−1. Other children need care because the retained child's size fell. The child had at least t+u selected terminals below it, so deleting one terminal leaves at least t+u−1 vertices in that child. Thus each other child's path demand is at most its unchanged order ≤u ≤ the remaining retained-child order; its competing inequality cannot obstruct target t−1. Positive t−1 and the join identity establish the drop. On the recipient-only route demand increases by at most one: the added P is a single path, union sums propagate, and its added size relaxes all competing-child inequalities at joins. At the least common ancestor the changes cancel in the upper bound on demand and the selected size grows by k−q>0. Above it, a nonincrease in demand and net increase in size propagates through all common unions and joins; for the root it preserves the Hamilton-cycle inequalities. Since all root competitors remain nonempty and total order≥3, the join criterion gives a cycle longer than X, contradiction.

Hence there are at least |S|+1 components of G−S containing a k-vertex path: each selected terminal is traceable on its selected vertices, and the unused terminal contains P. This proves (3) implies (2). The implication (2) implies (1) is immediate. Conversely a cycle that meets S has at most |S| runs outside S on its cyclic order, each lying in one component of G−S. A cycle missing S lies in only one component, at most |S| by nonemptiness. With at least |S|+1 components containing a k-vertex path, every cycle therefore leaves a whole such path outside it, proving (1) implies (3).

## Ore degree-sum corollary

For a supposed failure take the cut just constructed; its path-rich components all have order at least k. Put s=|S| and order all components by sizes a_1≤…≤a_r. One vertex from each of k+1 smallest components is independent with degree sum at most (k+1)(s−1)+Σ_{i≤k+1}a_i, since neighbors of each stay in that component or S. Subtract n+k(k−1) to get k(s−k)−1−Σ_{i>k+1}a_i≤−1, since at least s−k large components remain in that tail. This contradicts the degree-sum hypothesis.

- [Ma, Ning and Zhao, degree-sum conditions for long cycles](https://doi.org/10.1093/imrn/rnag249) and the [open Ore-type Bondy problem on ProofAtlas](https://www.proofatlas.ai/collaboration/ore-type-bondy-longest-cycle-conjecture/) give the unrestricted context. - Targeted and alternate live Google queries on November 27, 2026, did not surface the stated path-rich cut equivalence. This is a limited prior-art check, not a priority claim.
- Run `node research/ore-bondy-cographs/replay.js` from the repository root. The finite replay enumerates the canonical alternating cotrees of all 3,481 connected unlabeled cographs of orders 3 through 10. It calculates supports of paths and cycles by independent subset dynamic programming, tests the equivalence for all relevant k, and checks a cut contained in the marked support for each of the 962 longest-cycle supports leaving a path of order at least two. It checks the degree-sum deficit on 80 eligible (support, k) pairs. The four Lean lemmas verify arithmetic used in the proof, not the graph theorem.
