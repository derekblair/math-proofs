# Candidate for §5 question 4: limit need not exist 
Source [Hassler–Kirgizov](https://dmtcs.episciences.org/en/articles/16861), §5 q.4 asks whether the defining limit always exists. Build one length-9 avoidance class with two disjoint lanes, A and B. Allow precisely the order types of 9-consecutive windows in the following two doubly infinite families:
- A: direct sum of length-three indecomposable motifs 231 and 312, arbitrary independently for each block.
- B: value complement of the direct sum of length-three motifs 231 and 321 (so values decrease across blocks).

Equivalent finite definition at every n: choose leading partial suffix length l=0,1,2, trailing partial prefix length r=(n−l) mod 3, use t=(n−l) div 3 full blocks; choose each full motif independently, use any distinct realized partial suffix/prefix order types. Direct sums put every earlier block below every later block, and complement for B. Each positive length-two fragment has at most 2 possibilities: A prefix/suffix both 2, B prefix 2 and suffix 1. Length-zero and length-one fragments each one possibility.

A width-9 window is a restriction of a lane; its two width-8 overlaps include complete indecomposable blocks, whose positions are forced by the connected components of the inversion graph for A, and of the noninversion graph for B. Hence any adjacent windows have the same lane and same global block phase. Lane is unique because comparisons at distance ≥3 are always increasing in A and decreasing in B. Every block or pair of nearby blocks occurs within some fixed-length window for n>=9. Thus each complete block has one of its lane's motifs, each boundary partial block has one of its lane's allowed suffix/prefix order types, and every element of each successive block is below all elements of the next block (or above in B). By transitivity across blocks all cross comparisons are forced, so the allowable-word class is exactly the union of those two finite families (not just a subset). Phase uniqueness follows from existence of complete indecomposable blocks within any n>=9 sequence. This reconstructs permutations, since all ranks are determined by the pairwise comparisons.

Let n=3k+r. Count each lane by summing over l: boundary multiplicities s_l p_{(n-l) mod 3} times 2^floor((n-l)/3). In lane A the factors after extracting 2^k are 3,4,5 for r=0,1,2; in lane B they are 5/2,3,4. Therefore proportions for A are 6/11,4/7,5/9, respectively. Let q=231564897 (231 direct-summed three times), so q cannot appear in B. Within each phase of A, q can only start at a block boundary and matches iff three consecutive full blocks use 231. The first full triple in q is indecomposable, which rules out starting in a residual fragment of length at most two. For a phase with t full blocks, among all uniform independent motif choices, expected q count is (t−2)/8. Thus each phase's per-position rate tends to 1/24, independent of boundary phase. Unconditional rate has three distinct limits: 1/44, 1/42, 5/216. Check that the fractions 6/11,4/7,5/9 divided by 24 equal those values. Original limit therefore need not exist.

nonconv.py builds allowed words from the two templates, then independently enumerates all full-length avoiding permutations line by line via appending every possible next rank and checking the final window. It verifies exact lane union for each n=9..19, and reports actual frequencies. The independent Python scan is not a proof dependency.
