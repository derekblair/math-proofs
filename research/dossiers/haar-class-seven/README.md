# Girth and 64-cycles for cubic Haar graphs of class seven

For every group of nilpotency class at most seven and every three distinct ports, [HaarClass7Parallel.any_ports](HaarClass7Parallel.lean) guarantees a simple even cycle of length at most 46. The group need not be finite and there is no order restriction. This is an ordinary girth bound, not a claim that a power of two is guaranteed below 46. The general [Exoo–Jajcay nilpotent voltage bound](https://www.sciencedirect.com/science/article/pii/S0195669810001757), as in [Jajcay's slide 61](https://conferences.famnit.upr.si/event/28/attachments/44/180/jajcay.pdf#page=61), specializes to 128 for a three-edge dipole in class seven. This is a comparison to that bound, not a claim about absolute priority.

[HaarClass7HighGirth.any_ports](HaarClass7HighGirth.lean) shows that if there is no even simple cycle of length 4 through 32, there is a simple 64-cycle. This also holds for arbitrary finite or infinite group order. A third result, [HaarClass7ParallelActual.witness](HaarClass7ParallelActual.lean), uses explicit projected order and word-separation hypotheses rather than a girth assumption. [HaarClass7ParallelFactor.detects](HaarClass7ParallelFactor.lean) expresses the final word-separation condition as the nontriviality of a single explicit commutator.

The ordinary upper bound uses a cyclically reduced 46-step word whose value is a commutator of two words in the third lower-central subgroup that agree modulo the fifth. Those words commute in class seven. A shortest repeated-vertex interval then yields a simple cycle. The high-girth theorem uses a separate 64-step cyclically nonbacktracking word with the same commutation mechanism. Both the exact group operations and finite row tables are checked by Lean.

This dossier does not claim a sharp girth example, an unconditional class-seven dyadic theorem, or a proof of the full Erdős–Gyárfás conjecture. For a portable replay, run bash verify.sh /path/to/mathlib4 with Lean 4.34.1 and the built mathlib checkout d13f23b723b8a846827a245b89c10fc7d3f11612.
