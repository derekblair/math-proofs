# Single-failure sensitivity for compact rank-two affine graphs with a supplied feedback set

Let G be a directed graph represented by nonempty complete biclique blocks with copy weights wₕ(i,j)=aₕᵢ·bₕⱼ+cₕᵢ+dₕⱼ, aₕᵢ,bₕⱼ∈ℝ² (total M tail and head incidences), effective simple ordered-pair edges minimum over copies, n vertices. Given a feedback vertex set F of size f and fixed terminals s,t, verify the gate property and compute exact O((f+2)^2)-time single edge/vertex deletion queries after deterministic soft-O((f+2)^2(n+M)) preprocessing/space in exact arithmetic/comparison RAM. Reject an invalid supplied feedback set; otherwise detect whether the original graph has a negative cycle and, if it does not, build the oracle. If f=O(1), compact input yields near-linear preprocessing and O(1) queries even with quadratically many effective arcs and cycles. Quadratic polynomial blocks are a special case with head feature (x,x²). This is fixed-pair isolated failures, not online accumulated updates or arbitrary cycles. Witness walk reconstructs in time proportional to reported concatenation length, optional simplification zero cycles.

## Gate splitting and macro graph

Split each gate g into source g_out and sink g_in. Replace each original edge u→v by out(u)→in(v), with identity maps on non-gates. Every biclique remains one biclique, features and offsets retained, no size blow-up aside from O(f) vertices. The new graph D is acyclic iff G−F is acyclic: gate-out vertices have no incoming, gate-in no outgoing; representation support/toposort via incidence vertices tests it. A self-loop at a gate becomes a D edge from out to in, allowed; a self-loop at a non-gate would have invalidated the supplied F. All arc copies of an original simple ordered pair map to one split ordered pair.

For endpoint set U=F∪{s,t}, let macro weight u→v be exact D distance out(u)→in(v). It is legitimate for interior path to start/end at a non-gate terminal and traverse other non-gate terminals; every macro concatenation still gives a G walk. For edge failure map to the split pair and delete it in every D oracle. For non-gate vertex failure delete its same identity in every D oracle. Deleting a gate instead remove that macro vertex; paths between remaining endpoints cannot traverse either of its D copies, since one source and the other sink. Terminal deletion gives infinity immediately. A shortest original walk decomposes into D segments between visits to gates, including a no-gate s→t case; each D macro arc lifts to a real original walk avoiding the failure, with concatenation at identical gate. Thus macro distances exactly equal original post-failure distances. With nonnegative reduced weights (see below), dense-array Dijkstra and constructing all weights via DAG oracles both take O((f+2)^2); original distance recovered by terminal potential shift. If s=t and that vertex survives, return the empty path at cost zero. A macro loop represents a real original closed walk and poses no issue under nonnegative reweighting; can drop loops at query time. Preprocess D oracle for every endpoint pair, each Õ(n+M), plus potential. Forward/backward geometric indices and candidate choices could be shared across respective endpoints, but no better asymptotic claimed.

## Feasible potential or negative-cycle detection
 For each g∈F run one all-target forward D DP from g_out; record all distances to gate-in vertices to form f×f gate macro. Also run D DP with initial cost 0 at all original non-gates and at each gate-out (can initialize all vertices to 0, including gate sinks) to get best zero-origin starting seed to each g_in. A negative closed walk in G must meet a gate and implies negative gate macro closed walk by decomposition; negative gate walk lifts back, so equivalent. Run macro Bellman–Ford from virtual origin with directed seed edges to all gates (or initial seed labels), O(f³); if no negative cycle it computes φ_g (true original global zero-start shortest labels for gates, by first-gate decomposition). On D initialize g_out with φ_g and every other vertex with zero, then run forward DP. The resulting labels on interior vertices are true original global zero-start shortest labels by last-gate decomposition. Together φ is feasible: w(u,v)+φ(u)−φ(v)≥0. Time Õ((f+1)(n+M)+f³), dominated by main pair-oracle preproc for f≤n. Reweight each block by adding φ(u) to tail constant and subtracting φ(v) from head offset; feature dimension and representation size preserved. Deletion cannot introduce a negative cycle or invalidate a potential. Original negative graph rejected; not claiming individual failures that cure all negative cycles.

## Compact DAG primitive

The proof uses the following rank-two affine version of the [compact quadratic DAG cut oracle](https://github.com/derekblair/math-proofs/pull/111). The details here do not require code from that dossier.

Sort the DAG using an auxiliary virtual node per block (tails feed it and it feeds all heads). All tails of a block then precede all its heads. For a fixed pair of terminals, let αᵢ and βⱼ be the original shortest prefix and suffix labels. The cost of a crossing copy is αᵢ+wₕ(i,j)+βⱼ. For vertex rank r, minimize over i<r<j in the topological order, when the rank is internal to the terminals. For deletion of the edge (u,v), cut immediately before v and minimize over i<rank(v)≤j excluding (u,v). For cuts not separating the terminals, or non-forward deletions, use the original distance if neither terminal was deleted. These formulas follow because an admissible path crosses the cut once, and original optimal prefix/suffix paths at the ends of a crossing cannot use the failed object. A terminal deletion or originally unreachable pair returns infinity; a surviving identical terminal uses the empty path.

For each block a rank cut restricts at most one side: all tails precede all heads, so the crossing copies form one full side times a subset of the other side. Store the two distinct lowest finite crossing-score neighbors of each vertex on each side, using the unrestricted opposite side. For any cut and single pair exclusion, one of those two is sufficient for each vertex on the subset side. This leaves O(M) crossing records. Deduplicate retained records by effective ordered pair, keeping the best score; taking minima after blockwise exclusion handles overlaps even if not every pair's globally cheapest copy was retained. Sweep the active rank intervals, separately for the strict and inclusive cuts, storing the two best distinct pairs at each rank. A query indexes the appropriate rank and returns its first winner unless excluded. The sweep uses soft-linear time and space.

Forward DP and its top two per head use 3D support on points (aₕᵢ,cₕᵢ+αᵢ) in directions (bₕⱼ,1), adding dₕⱼ. Reverse DP uses points (bₕⱼ,dₕⱼ+βⱼ) in directions (aₕᵢ,1), adding cₕᵢ. Final labels on the supplying side are already known when the other side first needs the block. In these directions the 3D hull has a linear-size planar normal subdivision, with support located logarithmically using [Preparata–Hong](https://doi.org/10.1145/359423.359430) and [Kirkpatrick](https://doi.org/10.1137/0212002); handle lower-dimensional hulls in their affine span and break ties by returning any minimizing ID. Build the same indices on an endpoint segment tree to find the second ID by excluding the winner through a logarithmic canonical cover, keeping duplicate feature sites separate by endpoint. Ignoring infinite labels, each DP and its stored top two cost soft-linear time and space. Witness pointers can reconstruct each prefix, crossing and suffix.

## Scope and verification

[Lee–Lu](https://www.csie.ntu.edu.tw/~hil/paper/sidma14.pdf) study replacement paths in explicitly listed DAGs, where the edge count is the number of listed edges. [Gu–Ren](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ICALP.2021.76) give a bounded-integer all-pairs distance sensitivity oracle in a different graph and cost model. This theorem is neither an all-pairs result for unrestricted graphs nor an algorithm to find a feedback vertex set, and makes no priority claim.

- `node compact-gated-single-failure-replay.js` verifies the gate reduction and query semantics against explicit Bellman–Ford: 462 feasible signed graphs, 399 negative-loop tests, 4,598 edge deletions, 3,696 vertex deletions and 188 original gate loops.
- `CompactGatedFailureCertificate.lean` checks four supporting lemmas in Lean 4.34.1 and mathlib `d13f23b723b8a846827a245b89c10fc7d3f11612`. Neither artifact formalizes the full theorem, implements the geometric backend or benchmarks the runtime.
