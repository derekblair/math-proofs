# Topological-cut sweep for inclusion-minimal strong subgraphs with feedback parameter k

Starting with a finite strongly connected directed graph G and a supplied directed feedback vertex set F, size k, the algorithm returns an inclusion-minimal strongly connected spanning subgraph in deterministic O((k+1)^2(n+m)) time and O(m+nk+k^2+n) space. The k=0 case of a strongly connected graph has at most one vertex after ignoring loops, so return no arcs; the same output works at n≤1. Loops are unnecessary for reflexive reachability and are discarded. Parallel arcs may be stored as distinct indexed objects; the cut counts and degree counts use arc identities. This is **not** minimum cardinality optimization.

## Static algorithm

1. Build a split DAG: each a∈F gets copies a⁺ and a⁻. The tail of a graph arc incident out of a becomes a⁺, and the head of a graph arc incident into a becomes a⁻. All sources a⁺ precede ordinary vertices, which follow any fixed topological order of G−F; all pure sinks a⁻ follow. Original arc and vertex IDs can be kept with separate source/sink and topological-position arrays. No graph label changes during the sweep. Paths from a⁺ to b⁻ are precisely nonempty anchor-to-anchor walks without internal anchors. The strong connectivity of the directed relation on F induced by these paths is equivalent to mutual reachability of F in the current original graph: decompose any path between anchors at its internal anchor visits and vice versa concatenate the witnessing paths.
2. For every split DAG vertex x, precompute R[x], the set of sink anchors reachable from x in this **initial** DAG, by one reverse topological pass with set unions. Enter every source copy into the prefix at initialization, set L[a⁺]={a}, and add the contributions of all source arcs to a zero k×k counter matrix C. All source copies are brought in *before* the first edge attempt; otherwise some required paths could begin on the wrong side. Never enter the sink copies: every trial has all sources in the prefix and all sinks in the suffix.
3. At current cut every live crossing arc e=(u,v), u in prefix, v in suffix, contributes one to C[a,b] for each a∈L[u], b∈R[v]. Here L[u] stores which source anchors reach u by a live prefix path. Every split path a⁺→b⁻ crosses this topological cut **exactly once**, so C[a,b]>0 iff a⁺→b⁻ exists; C counts exposing arcs, not paths or disjointness.
4. Try original arcs by nondecreasing topological position of their split tails, starting with source tails. A trial is at a cut already containing its tail but not its head. If either original tail outdegree or original head indegree would fall below 1, retain the arc unconditionally. Otherwise temporarily subtract its one crossing rectangle, test strong connectivity of the support of C on F using two searches of k×k Boolean support, and erase the original arc and decrement its two degrees iff the test succeeds. For a reject, restore just that rectangle. Exactness: removing a crossing arc changes neither any prefix paths nor any suffix paths, so no other counts need change.
5. To advance the cut past the next ordinary vertex v, take the union of L[u] over its still-live in-arcs u→v. These arcs were crossing; remove their contributions using their old, unchanged R[v], then use the union as L[v]. Add all outgoing crossing arc contributions from v. None of those outgoing arcs has yet been tested, because every deletion uses a tail already entered.

### Invariants, correctness and resources

Every deleted arc has its split tail in the prefix, so the induced suffix graph of every cut is identical to the original split DAG induced on that suffix. Strict topological order implies a path starting in the suffix never leaves it. Therefore the precomputed R labels of all unprocessed heads stay **exact**, including during a trial. Likewise a prefix path to a processed tail cannot leave the prefix and return, and all edges internal to the prefix are already tested before each relevant L union; deleting an outgoing crossing from the current tail never changes the stored L values. Advancing the cut only changes membership of incidences at the new vertex, which is exactly Step 5. This proves invariants by induction starting from all pure sources. The only change on a rejected trial is modifiable counts; no reachability labels are rolled back.

Positive indegree/outdegree in the original graph, together with mutual reachability of F, is equivalent to strong connectivity for every spanning subgraph of G. In the forward direction this is necessary. Sufficiency: iterate predecessors from any vertex until meeting F, and likewise successors; if either exploration stays outside F indefinitely it repeats a vertex and yields a directed cycle in the acyclic G−F. A walk between arbitrary vertices can therefore join through the mutually reachable anchors. It follows that each trial is the exact naïve greedy deletion decision but runs in O(k²+1) time instead of recomputing reachability. Each retained arc was necessary when tried; removing other arcs never creates a path, so it stays necessary to the end. This gives inclusion-minimality, with no reliance on an approximate step.

Each arc enters the crossing counter once and exits at most once (it may point to a sink never entered); each probe costs at most two rectangle updates and two O(k²) matrix searches. Precomputing R and building L pass through incidences in O((k+1)(n+m)). The matrix fits k² counters each at most m, hence O(log(n+m)) bits each. Adjacency scans and topological sorting are linear. The dynamic frontier needs no per-arc reachability table: an arc's rectangle is rebuilt using only endpoint labels. One may release a prefix label after the last live outgoing crossing from its vertex leaves the cut, and a suffix label once its vertex enters; the stated space bound retains all labels for simplicity.

Comparison: this also gives O((k+1)^2(n+m)) unannotated time **after** finding a certificate for fixed k via the existing [linear-FPT DFVS algorithm](https://arxiv.org/abs/1609.04347); its parameter factor is not included in the supplied-certificate bound. The generic [Han–Kelsen–Ramachandran–Tarjan 1995 algorithm](https://www.cs.utexas.edu/~vlr/papers/minspan.pdf) gives O(m+n log n). [Simon WG'89](https://link.springer.com/chapter/10.1007/3-540-52292-1_18) explicitly claimed linear time in the unrestricted strongly connected case; the later [Kelsen–Ramachandran primary 1991 report](https://www.cs.utexas.edu/ftp/techreports/tr91-17.pdf), Introduction and refs. [12]–[13], reports that algorithm incorrect, citing Simon (personal communication, March 1990). This is a correction reported by those authors, not an independent disproof of Simon's algorithm. It prevents silently misrepresenting the history. The fixed-parameter sweep is a different construction; focused searches did not find the exact combination, but priority is not asserted and the comparison is with the established general baseline, not a claim to fastest among all promise-specific methods.

## Fully dynamic lift for a fixed supplied F

On the fixed vertex set accept arbitrary edge-deletion batches and any set of inserted edges incident to a single vertex, as in [Goranci–Karczmarz–Momeni–Parotsidis §§5.1–5.2](https://arxiv.org/html/2504.18161). The simple digraph is initially empty; the same F must remain a directed feedback set for **every** snapshot in the sequence. Theorem 1.1 of that source maintains exact transitive reduction of the single persistent DAG D=G−F in O(m) amortized time; each original update projects to one supported update or no change in D. No snapshot rebuild of this data structure is paid. Maintain current original graph adjacency and arc membership. Recompute SCCs and grouped condensation in O(n+m) on each update (dense component IDs and deterministic counting sorts; loops/duplicates can be omitted). Original graph IDs do not change.

For each distinct condensation component A containing F, compute Desc(A), Anc(A) including A; also for every component Y indicate whether an in-arc V→Y has V∈Desc(A) with V≠A, and symmetrically for each X whether an out-arc X→V goes into V∈Anc(A) with V≠A. Cost O((k+1)(n+m)). An inter-SCC edge X→Y is discardable if a genuine indirect path with at least two condensation edges exists. If any anchored component A is an endpoint, the in/out scan for that A tests **all** genuine indirect paths (endpoint included, no assumption on which original vertices a path visits). If neither endpoint contains F then both are singleton vertices outside F. An alternate path avoiding F is precisely an alternate path to their arc in D, detected by the exact maintained DAG reduction. Any other alternate passes through an anchored component A distinct from X,Y, detected by X∈Anc(A),Y∈Desc(A). Conversely these witnesses are genuine indirect paths, not endpoint aliases caused by a changing SCC decomposition. Output one original arc from each necessary condensation ordered pair.

Inside each current SCC X use the static sweep with k_X=|F∩X|. An induced SCC cannot require a path leaving and reentering it, and every cycle there meets the inherited F; `Σ_X (k_X+1)^2(n_X+m_X) ≤ (k+1)^2(n+m)`. Combining SCC reductions with a minimal condensation reduction preserves every original reachability relation and is inclusion-minimal. A retained internal arc cannot be bypassed by travelling outside because the condensation is acyclic. A representative inter-SCC arc realizes a mandatory condensation edge with no second retained representative. Thus fully dynamic amortized time is O((k+1)^2(n+m)) in the same batch convention as the DAG subroutine, plus reading updates. The quoted baseline for general digraphs is deterministic O(m+n log n) amortized. This gives linear time for every fixed k on the promised inputs (nontrivial log saving for sparse graphs), **not** for varying F, approximate cut relations, or merely bounded local SCC feedback with no bounded global F. Worst-case update time does not supersede the cited amortized DAG component. Static memory is linear for constant k; overall dynamic space inherits O(n²) from the DAG data structure, not a total linear-space claim.

## Verification

`sweep.py` independently reconstructs the live split DAG after every cut advance and every actual trial, computes source/sink reachability by graph searches and verifies **every count**, then validates inclusion-minimality by literal edge deletion. 5,636 graphs, 79,971 independent counter reconstructions, and 60,998 tentative deletions passed. Cases include all loopless tiny graphs under each tested anchor size up to n=4, plus random n=5..21 and k=1..n with shuffled anchor positions. The dynamic control deliberately brute-forces SCC decomposition and DAG reduction to verify the wrapper predicate, not to claim measured linear time. The Lean abstraction checks crossing existence, prefix/suffix invariance and finite counter decrements.

Final controls: `dynamic.py` passed 29,640 intermediate dynamic states with k=1..6, comprising 45,835 inserted arcs and 40,658 deleted arcs. `CutSweep.lean` replayed `crossing_iff`, `prefix_immutable`, `suffix_immutable`, and `counter_loss` with standard axioms and no holes. This checks the key mathematical abstraction, not an end-to-end dynamic implementation proof or independent proof of the cited DAG routine.

Additional scope: in a DAG with a specified list of required source–sink reachability pairs, add immutable pure-source and pure-sink stubs for all distinct origins and destinations. The same sweep tests whether every required crossing counter stays positive instead of testing strong connectivity of the anchor relation. This gives an inclusion-minimal feasible reachability network in O((p+1)(q+1)(n+m)+|R|) time for p distinct origins and q destinations and demand list R. It still does not minimize cardinality or total cost. It is a direct corollary of the written invariants, not a claim on the established optimal directed Steiner network problem.

The final replay also proves `CutSweep.single_rectangle_loss`: after removing a crossing arc, a source–sink pair is still reachable exactly when another exposing crossing arc exists with the **old** endpoint reachability predicates. This composes the local unchanged-label and crossing-factorization lemmas; parallel occurrences remain covered by the written arc-index variant.
