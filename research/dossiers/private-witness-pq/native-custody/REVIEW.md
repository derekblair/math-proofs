# Independent audit: native wire, fixed-contact ramp, limited snapshot

**Pass for the ideal trusted-volatile seed receiver, the static response cut, and the specified independent wrapper view extension, with the qualifications below.** Replayed 1,375 ramp checks and 231 integer width minima. No Lean end-to-end replay, novel KEM, performance or deployment evidence.

1. Fixed t, c<t≤n−f and field size ≥n+1: any t shares interpolate the polynomial of degree<t. For each e≤c fixed sites, the first e random coefficients give an invertible e×e Vandermonde block, so each view has exactly q^(c−e) low coefficient preimages, independent of the seed even with restricted padded secret-symbol image. Adaptivity: at any classical transcript, the as-yet-chosen label is determined by past classical labels/outputs and private (possibly quantum) state; for fixed seed, all earlier mask observation information is exhausted by the cache. Joint uniformity for each enlarged set makes the next fresh symbol uniform conditional on all prior observations, including seed-dependent public key/ideal CCA answers. That argument requires independent coins across tracks/epochs and no sharing-mask dependence in other authorized outputs, failures, metadata or side channels. Parties must not be asked to reveal one another's cached views, and count at most c distinct shares per track/epoch. Epoch refresh needs atomic replacement and no overlapping stored versions or correlated local-state views. If the native receiver allows flexible wrapper containers, reject challenge-equivalent base ciphertext queries precisely by the base CCA definition; single-family use is a conditional reduction only, and hybrid byte sums alone establish no secure active combiner.
2. Entropy proof correct: conditional entropy H(S|A,Y_J)=H(S|A) by zero leakage, the full responder word makes residual zero, and fixed widths upper-bound the complementary response entropy even with dependencies. Choose J to be the c longest words; shortly ordered widths yield H(S|A)≤sum shortest L, then total ≥ t·H(S|A)/L. For integral B get B+c·ceil(B/L); more generally sum shortest L is an integer ≥ceil(B), so ≥ceil(B)+c·ceil(B/L). If c=0 recover the ordinary full response entropy bound. For merely bounded variable length need account for framing or pad to a fixed representation; bitstring length can itself leak. The lower bound remains only static cut within a fixed selected set whose decoder has no other seed-dependent input; it doesn't price an interactive threshold transcript. If selection, public key or side advice reveals anything about S, use appropriate H(S|A). In the no-advice theorem the decoder is demonstrably able to recover from shares alone, so empty A and H=512 is legitimate even if an implementation also publishes the public key.
3. Arithmetic checked: with c63,t85,n130, w=24 ML-KEM and 12 HQC (q large enough). 255/127.5 payload bytes, latter 170 when each separate response is byte-aligned; aggregate 382.5 bit-packed or 425 individually byte-aligned, all excluding framing. 253-byte integer lower bound uses unequal-width allowance; uniform ramp is close, not proven optimal in every model. At fixed 64 contacts 4096 B ML-KEM and any n≥70 handles six failures, with the example still well within width floor. Sender ciphertext-only sums 1088 and 10066 versus 145600 and 1316900; envelope selected pad response amounts versus seed shares are not total network traffic. Use ‘public ciphertext core before authentication/framing’ rather than ‘unauthenticated’ if base KEM's CCA semantics might be confused with sender authentication. No energy, latency, or endpoint-payload claim across disagreeing chosen availability sets.
4. Volatile separation is existential about a full snapshot timed to a genuine *other* accepted operation while the same long-lived secret, or unrestricted equivalent, is active. Capturing arbitrary state after successful erasure, or an operation under a refreshed independent public key, doesn't imply exposure. In the limited wrapper a snapshot must exclude pending, executing, cached and later-to-be-reused challenge evidence, including any raw per-slot KEM key or reusable response/authorization state. Explicitly inherit the strong authenticated guard against ever evaluating the exact protected PRF input in a returned view, not merely checking exact ciphertext byte equality; full body/context must bind all session-relevant details or inherit the one-time signature-on-canonical-body reasoning. At a distinct authenticated context, repeated identical base capsule uses same challenge candidate in KEM simulation and different PRF input. Proof lifts only if exported share and aggregate output are deterministic from allowed-context data and pads, no side transcript reveals other protected state. The oracle's inputs/outputs are classical (even against QPT); no quantum memory/superposition/disclosure claim. Usual per-primitive error already scales with added query resources; no new support-guess term.
5. Scope vs prior: fixed-contact ramp and entropy communication cuts are classical (Huang–Langberg–Kliewer–Bruck arXiv:1505.07515; Bitar–El Rouayheb arXiv:1512.02990). Exact wire-compatible threshold MPC resources concern an entirely different trust, corruption, interaction and response model: they cannot be excluded by a reconstruction cut or volatile seed exposure. Treat Ta et al. native Scheme A vs separate noncompatible Scheme B, HQC threshold PKE vs full native threshold CCA KEM, and Amber native-to-its-own-format vs ML-KEM ciphertext compatibility as distinct. Source links in dossier are the proper provenance; numerical threshold figures read from the dossier were not independently fetched for this no-remote audit. Claim the ideal architectural tradeoff, not novelty of threshold sharing or unconditional superiority.
