# Sharp dyadic-cycle bound for odd nilpotent metabelian one-matching bi-Cayley graphs

For every finite odd-order nilpotent metabelian group G, regardless of
nilpotency class, and nonidentity x,y, the one-matching ribbon has
a simple C4, C8, C16 or C32. The bound 32 is sharp even for class three.
With the weaker hypothesis that the derived subgroup has class at most
two, the same conclusion holds with C64 added. Sharpness at 64 is not
proved in this dossier.

The graph has vertices (side,g), edges for right multiplication by x±
on the false rim and y± on the true rim, and a single spoke joining
(false,g),(true,g). In odd finite order with nonidentity generators this
is simple and cubic. It is not the three-cross-matching Haar case.

The strongest metabelian local theorem requires no finiteness,
generation, or nilpotence. Write c=[x⁻¹,y⁻¹], and C for its image in
G/γ₃. If C⁴≠1 the ribbon has a simple C32; in finite odd order it
suffices that C≠1. If C has order other than three, use the first half
of the class-six word (its class-two chart requires powers 1–4
nontrivial). Its endpoint is the conjugate by y⁻¹x of
[[x,y⁻¹],x⁻¹[y,x²]x], which is trivial in a metabelian group.

For exact order three use the new word
12002002121121200200211212002121 (forward/back/spoke).
It is a 30-position rotation of the earlier class-five A with rims
swapped. The rotated endpoint is x⁻¹ trace(y,x,A) x.
Writing H=[x,y²], trace(x,y,A)=x[H,x⁻¹H⁻¹x]x⁻¹, likewise trivial
by metabelianity. The 32 rows (rim,y^j x^i c^k) have distinct
(rim,i mod 3,j mod 3,k mod 3). In the class-two quotient, equal normal
forms imply equal i,j modulo three by commutation with the generators.
The narrow chart windows [-1,1] and [0,2] force equal integer i,j.
Canceling then recovers equality of k mod 3, contradicting the finite
chart. metabelian_mitm.py independently found the witness by matching
exact lattice edge flows; the formal proof does not depend on that
script or a general Magnus embedding theorem.

Restrict to the subgroup generated by x,y. If C=1, the class-two
quotient is generated by a commuting pair, hence γ₂=γ₃. The lower
central series remains constant there and nilpotence makes it trivial.
The commuting-rim case supplies C4/C8/C16, and otherwise the local
theorem supplies C32. Inclusion preserves the cycle. The UT₄(F₁₁)
sharpness certificate is metabelian because γ₂ commutes with γ₂ in any
class-three group; it excludes C4/C8/C16 and includes C32.

For the class-two derived group extension, the class-six chart residue
R is a conjugate of a commutator of two derived elements, so R
centralizes the derived group. Since R=UV and U is derived, UV=VU,
giving exact closure of the 64-word. If R≠1 then the residual
same-coordinate pairs are distinct, and if R=1 the 32-step prefix
is already a cycle. The characteristic-three quotient character chart,
inversion compatibility and lower-layer stabilization work as before.
