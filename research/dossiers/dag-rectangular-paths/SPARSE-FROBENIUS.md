# Faster disjoint (shortest) paths on sparse directed acyclic graphs

**Theorem.** For every fixed k≥3 and c>0, directed DAG k-DP and arbitrary-real-weight DAG k-DSP admit one-sided randomized algorithms with failure probability ≤n^(−c), expected Õ_k((m+n)n^(k−2)) time to report a solution, and the same worst-case time for detection. No false solutions are returned. For m=O(n), this is Õ_k(n^(k−1)), e.g. quadratic for 3 pairs and cubic for 4 pairs. This is not a result for cyclic directed graphs, arbitrary independently labeled commodity arc sets, or deterministic detection.

**Comparator.** [Cao–Qi–Wang arXiv:2611.02154v1](https://arxiv.org/html/2611.02154v1) Theorem 4.7 gives O_k(m+n^(k−3+ω+ε)) with the same correctness and field/RAM model. Its then-current <2.372 square bound can be upgraded to 9/4 using [Amanov–van den Berg–Zuiddam](https://arxiv.org/abs/2610.30054) Theorem 1.1, yielding n^(k−.75+ε) on sparse graphs. The local earlier rectangular algorithm is n^(k−1+1/[4(k−2)]+ε) for k≥4, including n^(25/8+ε) for k=4; our sparse bound also strictly improves that known guarantee. Off sparse graphs one can simply select the faster proven branch. This is a new faster circuit for these routing problems, not a matrix-multiplication speed or priority claim.

## Shared variables and common same-event kernels

Normalize parallel arcs first by keeping one minimum-length arc for each ordered pair (any one for ordinary DP). Different choices of minimum parallel arc do not affect whether vertices used by different paths intersect. Work on a DAG with a fixed common topological order. For shortest paths let H_i be the original source-tight subgraph formed from finite directed source distances `d_i`; i.e. an arc uv belongs if d_i(u) finite and d_i(v)=d_i(u)+length(uv). For DP each H_i is the same whole original graph. The choice of one formal variable x_e per original arc, shared by all commodities that contain it, **is already the source's convention** (Theorem 4.1 and opening §4), not a specialization of its independent variables. The input real lengths are separate from these field variables. Source Lemma 3.1 proves distinct disjoint tuples have distinct squarefree monomials: an original union of directed edges determines each of its vertex-disjoint directed components and hence its commodity by distinct prescribed endpoints, while a zero-edge pair is forced and still occupies its terminal. Coincident terminals across commodities are rejected. The private source and sink edges of the collision circuit have constant value 1, are outside the real-vertex order, and never appear internally on a path from one real vertex to a later real vertex.

For a region R (any common induced vertex subset) and later real vertex v>w put N_i(w,v) equal to the path-sum from w to v in H_i[R], evaluated formally in characteristic two. Let H_ij=H_i∩H_j. Then
    N_i(w,v) N_j(w,v) = N_ij(w,v)^2,
where N_ij is the path-sum in H_ij[R]. For ordinary DP this follows by equality of masks. For shortest paths, if either combinatorial path family is empty, both sides are zero. If both exist, each H_i path telescopes to d_i(v)−d_i(w), a global lower bound on length by nonnegative shortest-path slacks; hence each is globally shortest w→v. Likewise for H_j. Now every arc of an H_i path is eligible for a slack relative to d_j (w is reachable from s_j, so all later vertices along this path are reachable). The sum of these nonnegative slacks is exactly length−(d_j(v)−d_j(w))=0. All are zero, so this same path belongs to H_j[R]. The reverse inclusion follows symmetrically, and the two path families equal the intersection family. No strictly positive arc lengths are needed: a common DAG has finite shortest distances whenever reachable and no cycles. The same argument covers endpoint-trimmed masks if both endpoints remain on their own original shortest routes, by appending the known requisite prefixes/suffixes; our implementation need not apply any such extra trimming.

By Frobenius **as a formal polynomial identity** in characteristic 2,
    N_ij(w,v)^2 = Σ_{P∈paths_{H_ij[R]}(w,v)} ∏_{e∈P} x_e².
Thus a path propagation using the original intersection subgraph and squared arc variables computes the same-event Hadamard kernel in all necessary dimensions, without constructing a dense matrix. A dummy label used for a missing regional pair consists of a new isolated real vertex carrying its own zero-edge pair; it has no real arc and thus all its N_i(w,v) between distinct real vertices are zero, trivially consistent with this identity. Private normalization terminal arcs never intervene between two real meeting vertices. No identity is asserted on a pair of arbitrary commodity masks (e.g. the two privately routed sparse backbones in the prior obstruction).

## Divide-and-conquer collision circuit, using no dense multiplication

Use source Lemma 4.2 with prefix collision rows Λ_T(w;·) grouped by first common real vertex w and set T of labels at w (|T|≥2), extensions Y_T^w, and the same eventwise direct expressions into future destination rows. Use topological recursion: at a nontrivial contiguous real interval I=I₁<I₂, finalize all rows in I₁, compute and apply all contributions from w∈I₁ to v∈I₂, then recurse on I₂. Every pair of real w<v is processed exactly once. A leaf finalizes each Λ by subtracting its accumulated earlier collisions from the independent prefix product. Let h=|I| and N=O(n) including private vertices.

1. **Path-sum and extension scans.** Compute N_i by n topological sweeps, cost O_k(n(m+n)), already within the bound for k≥3. At a merge compute required Y_T^w for the finalized left cohort separately by source §4.2 first-arc/last-arc scans, not by matrix multiplication. For each fixed w and each outsider label axis (at most k−2), and fixed other outsider coordinates, transmit below-w coefficients through arcs from c<w to d>w, and propagate on the later subgraph; retain identity for e<w, zero for e=w. One scan costs O(m+n). There are O_k(h N^(k−3)) fibers per merge when at least one outsider axis exists, and zero transport for no outsiders. Outputs at e beyond the end of I are not read in this merge, so may be truncated; later root sink evaluation uses one additional full-region cohort of this cost. Recomputing cohorts at each depth instead of keeping all former transforms incurs only a logarithmic factor.
2. **Distinct-event target pair.** For target pair S and source event T≠S, choose j∈T∖S as in source §4.4. For fixed destination meeting v and remaining k−3 outsider endpoints, all factors except N_j(w,c_j) are independent of c_j. Put their product into an initial vector at each w∈I₁ (zero elsewhere) and propagate once through commodity j. The value at each c_j equals Σ_w P[v,w] N_j(w,c_j); scatter to original entries only when c_i<v as in source. A full O(m+n) scan is allowed here: there are O_k(h N^(k−3)) rows and h sums O(n) per depth. In particular a destination c_j in the left half, but later than w, is handled correctly, not dropped.
3. **Same-event target pair.** For T=S={i,j}, fix the entire k−2 outsider tuple c, give each w∈I₁ initial coefficient Y_S^w(c), and propagate once in the squared-weight shared intersection H_ij[I]. Read contributions at v∈I₂. The common DAG order ensures every path between such w,v stays inside I, so this cost is O(m_I+h) *per tuple*, not a scan of all m per merge. Across one depth the intervals are vertex-disjoint and total induced adjacency size is ≤m. There are O_k(N^(k−2)) outsider tuples per merge and only constantly many pairs. Preserve the destination mask c_i<v exactly. Creating the initial vectors, reading, and scattering costs O(h N^(k−2)) per merge even for tiny h, charged to the same bound.
4. **Larger target collision sets.** For |S|≥3 use direct updates, as in §4.4. Total over all pairs w<v and all outsider tuples is O_k(n²·N^(k−3))=O_k(n^(k−1)), absorbed by n in (m+n). Final root sink tuple formula subtracts all first-collision terms, using the one extra full Y cohort with private sinks present.

Every arithmetic operation is single-field addition/subtraction/multiplication with a combinatorial schedule, so it yields the identical division-free formal polynomial circuit and emits in linear time in its gates. Syntactic squares are valid, and equivalent formal circuits have identical formal derivatives, including in characteristic two. The above time is O_k((m+n)n^(k−2) log(2+n)) field operations, before source-model polylogarithms. Storage of finalized rows, accumulators, and one active cohort is O_k(n^(k−1)) field cells.

## Reporting and error

Use source §3 / Proposition 4.6 correlated extraction and topological median reporting. The regional instance there is explicitly H_i[R] with changed terminals *inside a common vertex region*, not label-specific deletions. Our circuit works on every such region, including the added isolated zero-edge labels. Source edge parallel-normalization is redundant after the initial globally normalized simple DAG; no asymmetric label pruning is needed. The same shared original edge variables apply in every regional call, and extractor substitutions and derivative gates act on those variables. Initial test over the source's polynomial-size extension of F₂ has one-sided false-no probability at most n/|F|; conditional on a nonzero evaluation the extractor returns verified paths without further error. Selection of edge-label orientations remains the source's ordinary directed topological choice; we never identify edges of opposite direction. At reporting depth t, disjoint regions obey Σ_R m_R≤m, Σ_R n_R≤n, and n_R≤O(n/2^t), so (m_R+n_R)n_R^(k−2) sums geometrically for k≥3, with log factors and dummy padding absorbed. This proves unweighted and arbitrary-real-weight graph-search as claimed, not merely root polynomial evaluation.
