# Local feedback can be reused along the SCC order

Separate deterministic companion result. Let U be the union of true original directed shortest-path supports D_i after reserving trivial terminals. Suppose each SCC C of U has a directed feedback vertex set F_C of size at most g. For fixed k,g≥1 there is a deterministic exact routing algorithm in O_{k,g}((m_U+n)n^{k+g−1}) time (plus original distance computations). No dependence on the total feedback number in an exponent or parameter prefactor. For sparse support this is O_{k,g}(n^{k+g}); it improves the global-clone bound when total visited feedback is sufficiently larger than local maximum, but is not uniformly faster for a single cyclic component. Linear-FPT DFVS can find all sets with total f(g)(m_U+n) work. The supplied sets may contain terminals.

## Shared/global state

As in the SCC audit, process the condensation topologically. For each label keep one next-entry token, at some vertex of a current or later SCC, or DONE. Reject shared original terminals and unreachable pairs, reserve trivial pairs without changing stored original distances, and initialize distinct pending positions by s_i; labels whose next point is outside C pause while C is processed. We select actual labelled arcs only from the original D_i; every future witness therefore telescopes to the original shortest length, no local distance promotions. One may remove other labels' terminals from each D_i after original distances are computed; this loses no valid solution. SCCs may be computed before these safe per-label arc removals.

At entry to C admissible labels are precisely those whose next vertex lies in C. Choose assignments of F_C vertices to one of these labels or unused. If a label's entry is in F_C reserve that original vertex for that label as its first feedback visit; it does not require a local in-fragment, because it is already the head of a selected previous component edge, or the original source. If a label's target is in F_C, reserve it as its last visit ending the last local fragment, with no outgoing segment. When entry equals target, no other visits of that label are permitted and the path occupies its entry as a singleton. Other visits of each label are in strictly increasing original d_i order. Ties or contradicting a prescribed endpoint reject the branch. The identities of entrants, assignments, and which entries are in F_C (and which ones) have only O_{k,g}(1) possibilities per component.

Now clone F_C inside C exactly as in CLONED-FEEDBACK.md, retaining all original labels on arcs. Give each entrant one existing token for its final fragment, and at most one extra token per visited feedback vertex for earlier fragments. All ordinary entries begin at themselves; a feedback entry begins at its plus clone, with no empty initial minus fragment. A feedback target goes to its minus clone. A singleton fragment occupies its vertex until it is the earliest active token and retires. A trivial original pair reserved beforehand deletes its original vertex and, if applicable, both clones. Every nonfinal fragment has fixed terminal of type v⁻. A final fragment either has prescribed original target (if t_i∈C), or takes any actual outgoing arc of D_i into a later SCC and then pauses there at its original head in that label's existing slot. There is no guess of an outside endpoint, and a nonfinal fragment cannot leave C. A feedback F→F arc is one plus-to-minus move. An outgoing arc from x∈F_C uses its plus copy; one to a feedback vertex of a later component sets an ordinary pending original entry, to be interpreted anew in that component. A wrong sink copy has no outgoing continuation and is rejected; plus copies have no incoming arcs. Distinct prescribed ownership ensures two clones of one original vertex are used only as the consecutive joins of one original label.

## Earliest-token DP and accounting

Fix C and one assignment-pattern type (including identities of entrants and type of feedback entries), and combine all incoming states with that type in one local DP. The number of coordinates is at most p=k+|F_C|: outside pending tokens remain fixed throughout this phase, but may differ across the initial histories merged into this DP. Label slots and designated local targets are determined by the pattern. Choose a fixed topological order of the cloned C. Ignore outside tokens in the choice of the earliest current inside token, and advance that token on any allowed original edge, or retire it if it is at its prescribed terminal. A token that has reached a target is not retired until it is earliest. Pause an exit token outside immediately but keep its original next coordinate. Never advance onto another current token vertex; for pending original entries outside, reject duplicates there as well.

After each step any interior vertex no longer held by a token lies strictly before all inside pending tokens in the C order. Initially this is vacuous, and it remains true because only the earliest token can vacate or retire at its position, and next arc inside goes strictly later. Thus no future inside token can collide with forgotten history. Every collision with a not-yet-advanced fragment start is visible as a token collision, and retired target vertices cannot be reused later (strictly earlier); original paths reaching fixed terminals are handled with the same rule. A local start no longer used need not be stored as historical information. The only exceptions are intentionally identified paired F clones (different vertices locally, same original ownership), not collisions. For completeness any witnessing clone tuple permits this fixed schedule: advance each current least token along its next witness edge or terminate, never causing a collision. Fragment traversal can occur in conceptual order or not; reconstruction concatenates by own assigned feedback order after all fragments have been certified. All local fragments must finish before passing any paused label to the next SCC, so this is not prematurely advancing the original path.

Charge expansions for an inside state to its earliest token vertex x. Once its slot and x are fixed, at most O_{k,g}(n^{p−1}) distinct coordinate vectors remain, allowing DONE/paused status as constant flags. All expansions at x cost that quantity times 1+outdegree(x) in the cloned C including its permitted external exits. Summed across components, the number of clone vertices is n+Σ|F_C|≤2n and every original arc has one source incidence there, so O_{k,g}((m_U+n)n^{k+g−1}). At most n^k original coordinate states need classification per SCC, total O_{k,g}(n^{k+1}), absorbed for g≥1. If no inside token remains, output the paused/done state, which is now the ordinary SCC-phase state. Deduplicate exact token vectors. Implementation matters: allocate once a direct-address table for the padded at-most-k+g coordinates with constant status flags, O_{k,g}(n^{k+g}) initialization, and use generation stamps per component/pattern. Fixed-length radix encoding costs O_{k,g}(1) word operations; no full table clear per component. Store immutable predecessor records separately for first discoveries and completed boundary states, so replacing table entries on a new generation does not destroy an earlier accepting trace. Their total creation time and storage are bounded by the stated time bound. Reconstruct the labelled arcs from the resulting trace. No multiplicity inference or randomization is needed. For g=0 use ordinary deterministic DAG pebbling or the faster randomized DAG solver directly.

The parameter separation is real: take a sequence of disjoint SCC gadgets connected only forward, each with one feedback vertex, and add distinct paths through those gadgets if desired. Global feedback number can grow linearly in the number of SCCs, yet g stays one and the stated exponent fixed. This is a routing-state argument, not a claim about finding a particular globally optimal witness or about the best known unrestricted cyclic bound.

Replay `python scc_feedback_check.py` for exhaustive original shortest-path tuple comparison on 146 finite reachable instances including 12 genuine cyclic SCCs and 762 expanded local token states, with common shortest-support filtering, feedback entries, route choices and parallel gadget SCCs. The `split_check.py` proof control is separate (441 original/clone instances, including forced direct F→F arcs).
