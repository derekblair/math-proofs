# Terminal splitting removes neighbor guesses for positive-weight directed k-DSP

**Theorem.** Let U be the union of the original source–target shortest-path edges in a directed positive-real graph, and let f be its directed feedback vertex number. For fixed k≥3 and f, original shortest disjoint routing can be found with one-sided randomized error in expected Õ_{k,f}((m_U+n)n^{k+f−2}) time after original shortest-distance preprocessing. A feedback set need not be supplied: the linear-time-parameterized algorithm of [Lokshtanov, Ramanujan and Saurabh](https://arxiv.org/abs/1609.04347) finds one in parameter-only overhead times m_U+n. The exact dependency in the new branching step is at most (k+1)^f. Compare the earlier scoped edge-guess bound Õ_{k,f}((m_U+n)n^(k+3f−2)) in FEEDBACK-TRIM.md. This is not an unrestricted cyclic-input speed claim. The technique of vertex splitting itself is classical, e.g. the skew-separator reductions of [Chen et al.](https://drops.dagstuhl.de/entities/document/10.4230/DagSemProc.07281.5), not a novelty claim.

## Clone graph and assignment

Reject reuse of a terminal across distinct commodities or infinite original source-target distance. Normalize parallel arcs by keeping a least-length copy. Compute original d_i from each s_i (and reverse distances to t_i for U trimming); the support test d_i(u)+length(uv)+dist(v,t_i)=d_i(t_i) gives exact full shortest-path edges, as concatenation yielding a repeated vertex could be shortened by removing a strictly positive cycle. If some s_i=t_i, reserve that vertex, remove it from the *routing support* and remove that trivial label; original distances of all remaining labels stay as originally computed, so removing a reserved vertex never promotes a formerly longer path. If needed for feeding a k≥3 base solver, pad with a constant number of isolated trivial labels. Below, k denotes the original number.

Find a feedback set F in U. Replace each v∈F by two distinct clones: a source-only v⁺ with its original outgoing arcs, and a sink-only v⁻ receiving its original incoming arcs. Every original uv is represented exactly once, retaining its length: use u⁺ if u∈F and otherwise u at its tail, and v⁻ if v∈F and otherwise v at its head. An F→F edge becomes u⁺→v⁻, not a two-edge path, and is not duplicated. The result is a DAG since an arc path cannot enter a plus clone or leave a minus clone, and U−F is acyclic.

Enumerate assignments of each nonterminal vertex of F to unused or one original commodity. A terminal of a nontrivial commodity must belong to that commodity and contributes only its proper end copy: source s_i⁺ or sink t_i⁻. A nonterminal assigned to i must lie on some original shortest i-path (test d_i(v)+dist(v,t_i)=d_i(t_i)); its order on any such path is by strictly increasing d_i. Equal-distance assigned vertices of the same commodity cannot both occur on one shortest path with positive lengths. Thus every candidate visit order is determined by this assignment and is not guessed; validation optionally checks that the source/sink lie at the strict endpoints of this sorted chain.

For visits v_1,…,v_j on i, create fragment pairs
    (s_i or s_i⁺, v_1⁻), (v_1⁺, v_2⁻), …, (v_j⁺, t_i or t_i⁻).
If j=0 make just the original pair with proper endpoint clones. Every fixed branch has k+j_total or fewer genuine pairs, with j_total≤f. Distinct commodities cannot share a clone. Plus or minus copies not prescribed as endpoints cannot be used by any fragment, since they are sources or sinks, respectively. If outside the branch an arc led directly from v_a to v_{a+1} in F, the corresponding one-edge fragment is feasible and consumes one representative of that original arc. Terminal singletons were reserved separately, and repeated phase visits are excluded by assignment.

## Exact lengths and completeness

In the common clone DAG, compute exact shortest distance of every prescribed fragment. Reject the branch if some fragment has no route, or the sum for one original pair differs from its original d_i(t_i). If a genuine shortest path tuple induces the branch, its pieces cannot individually be improved in the clone DAG: a shorter clone path between a piece's endpoints maps to an original walk, thus would form a shorter original source-target walk. Removing any repeated-vertex positively weighted cycles gives a still shorter original path, contradiction. Thus a true solution supplies simultaneously disjoint shortest clone fragments and passes the length check.

Conversely if the branch passes and its clone fragments have a disjoint shortest solution, map clones back and concatenate at the consecutive paired copies v⁻/v⁺. No outside vertices are reused across fragments, including within the same final commodity. Each feedback vertex is assigned once, and a fragment can visit it only at its designated extremity, so mapped vertices are repeated only at the intended join, where one occurrence is dropped. Thus these are simple disjoint original paths, and the sum check certifies shortestness. There is no need to guess branching edges nor to label clone arcs independently per fragment: each fragment is a genuine shortest-path pair in a *common* real-weight DAG, allowing the sparse Frobenius reporting theorem. Because preprocessing removes ambient edges not used by any original shortest path but never adds one, all shortest comparisons against stored original distances remain sound.

## Time, error, and finer regimes

The clone graph has n+f vertices and m_U arcs. At most (k+1)^f assignments, each requiring O_{k,f}(m_U+n) preprocessing for topological distances before routing plus Õ_{k,f}((m_U+n)n^{k+j_total−2}) routing, with isolated padding if fewer than three actual calls require it. This gives the stated worst-case. In sparse retained support it is Õ(n^(k+f−1)) for fixed parameters. One-sided failure is bounded using any fixed successful branch and overestimation of the main solver's failure parameter; returning YES always supplies valid checked paths. Iterating by j_total gives witness-sensitive YES time with j_total in place of f in the n exponent, while retaining the full parameter-dependent assignment overhead. General U not assumed sparse; use the faster existing DAG decoder where appropriate. If the parameter varies with input, the base solver's constants in k+f and FPT search overhead must remain explicit, not treated as universal.

`python split_check.py` independently compares exact clone branching with direct exhaustive original shortest path tuples on bounded random cyclic graphs. It also checks feedback F→F, feedback terminals, capped branch distance, forced trivial reservations, and reconstructs exact path witnesses rather than only checking feasibility.
