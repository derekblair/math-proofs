# Dyadic cycles in abelian covers of K3,3 and the ten-vertex Möbius ladder

More than the characteristic cover works. Let A be any abelian group with no nonzero element of order two, and let W be any antisymmetric A-valued edge assignment on K3,3. The derived graph has a simple cycle of length 4, 8, 16 or 32. Connectivity, arc transitivity, a particular finite exponent, and a universal homology kernel are all unnecessary. In particular this holds for every finite odd abelian deck group.

**Lean entry points.** `HaarK33OddCover.any_cover` and `HaarK33OddCover.finite_odd`. A graph point is a base vertex and a deck-group coordinate; adjacency adds the assigned directed edge voltage. The cycle is an injective map from `Fin n` with all consecutive and wraparound edges. The final finite-odd axiom report is only `propext`, `Classical.choice`, and `Quot.sound`.

**Haar graph corollary.** [HaarK33AllPorts.any_ports](HaarK33AllPorts.lean) gives a simple cycle of length 4, 8, 16 or 32 for every normalized triple of distinct ports in a finite odd-order group admitting a homomorphism to the cyclic group of order three with abelian kernel. In particular this applies with an abelian normal subgroup of index three, without a nilpotency-class bound. For distinct quotient port images the proof transports the abelian cover certificate to the original graph. For two images or one image it uses separate short-word constructions, which are also checked in Lean. The two-image branch works with an arbitrary quotient group.

**Proof architecture.** Gauge away a specified spanning tree and identify the remaining edge voltages with images of the four basis vectors in Z^4. The root has no vanishing relations. At each node, its candidate word has voltage zero modulo already assumed relations: explicit integer coefficients express a power of two times that voltage in their span, and there is no 2-torsion. If the lifted walk is not simple, a same-base-vertex pair has equal deck coordinate; their enumerated voltage difference vanishes and gives one child. Each child’s relations follow by the same integer expressions and cancellation of powers of two. All child indices decrease. The Lean checker verifies each closure identity and pair-to-child witness by kernel reduction; it does not trust a Python pass, the search method, or any Smith/Hermite calculation.

**Reproduction.** `python3 check_cover_certificate.py` independently checks the supplied JSON by plain integer operations. To regenerate it, run `python3 cover_branch.py` (uses SymPy 1.14.0). Then `python3 gen_cover_lean.py` regenerates bit-for-bit the Lean data and 17 check shards. The current certificate has 259 states and 469 branches, and no cancellation factor exceeds 8. For a clean Lean replay, run bash verify.sh /path/to/mathlib4 with Lean 4.34.1 and built mathlib commit d13f23b723b8a846827a245b89c10fc7d3f11612. The Python tools are optional and are not part of the Lean proof.

The standard voltage construction and spanning-tree gauge are not novelty claims. Prior work includes [Conder–Ma, Arc-transitive abelian regular covers of cubic graphs](https://www.gregas.eu/publications/preprints/conder-arc-transitive-abelian-regular-covers-of-cubic-graphs) on classifying symmetric covers; the present cycle bound does not assume symmetry. This is a restricted Erdős–Gyárfás result; arbitrary odd-order Haar graphs and arbitrary cubic graphs are not settled here.

## The ten-vertex Möbius ladder and odd index-five extensions

[HaarC5OddCover.any_cover](HaarC5OddCover.lean) applies to the 10-vertex cubic Haar graph on two copies of C₅ with ports 0, 1 and 2. It is the ten-vertex Möbius ladder: send a left vertex u to 4u modulo 10 and a right vertex v to 4v+1. The three port differences then give rim offsets +1, −1 and the opposite chord +5. Every abelian regular voltage cover of this base over a deck group with no nonzero 2-torsion has a simple cycle of length 4, 8, 16 or 32, without a connectedness or symmetry assumption.

[HaarC5AllPorts.normal_abelian_index_five](HaarC5AllPorts.lean) gives the same bound for cubic Haar graphs over finite odd-order groups with an abelian normal subgroup of index five, for all distinct normalized ports. When the images are distinct, the affine classification of triples in C₅ reduces them to 0, 1 and 2. When images repeat, use the earlier short-word lemmas. This has no nilpotency-class hypothesis. Neither all odd-order metabelian groups nor arbitrary cyclic quotients are claimed.

The exact finite certificate has 1,158 states and 1,978 branches, with a maximum dyadic cancellation multiplier of 8. To reproduce, in c5-certificate run python3 check_c5_certificate.py for the standalone exact-integer check. Optional generation is python3 c5_branch.py (SymPy 1.14), then python3 gen_c5_lean.py in a scratch directory with the JSON. Lean's verifier checks all 49 theorem shards and the transport independently of Python. Run the parent verify.sh for both cases.
