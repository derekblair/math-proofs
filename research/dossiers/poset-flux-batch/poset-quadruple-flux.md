# Exact four-way linear-extension order marginals without matrix multiplication

Given an indexed ideal DAG (J ideals, E labeled cover arcs) and a w-chain partition, write all counts N(x before y before z before t), including zeros for repeated labels. First algorithm: for each first middle arc e:I→K=I+y, propagate paths from K through the ideal DAG. For each later arc f:L→M=L+z reached, let v=F(I)·paths(K,L)·B(M), where F and B are standard forward/backward counts. This is exactly the number of full extensions using these two arcs; concatenation is independent, and each such extension has uniquely those y,z arcs. Its first and fourth labels range over x∈I, t∉M. Intersect with each of w² ordered chain pairs: prefix at I × suffix outside M; add v via four signed corner writes in a difference table keyed by y,z and those chains. Sweep each grid once to output all counts. Cost O(n⁴ + w² E² + JE), equivalently O(n⁴ + w² E²) since E≥J−1 for nontrivial DAG. Streaming by y needs at most O(n³+J+E) count words (for fixed y the distinct e all have distinct head K, and rerunning any source used for a different y is already charged per e). At width two J,E=O(n²), yielding O(n⁴) arithmetic, optimal for explicitly writing n⁴ count entries; no claim of priority or unrestricted speedup.

Only inspect reachable states after K, using FIFO rank layers (all paths K→L have same length), accumulating sums and sparsely clearing touched labels. Then actual middle work is O(w² sum_e E_{head(e)}), where E_K reachable outgoing arc count, plus negligible one initialization per e, rather than w² E². This sensitivity can matter for sparse upper intervals. Cover arcs, chain prefix lengths and membership can be obtained as in prior pair/triple proof; add construction indexing separately.

Alternative O(n⁴+n²wE), using O(J+E+n²) working count words by streaming first pair (x,y). Propagate scalar G_{xy}(L)=#prefix paths ending at L in which x,y already appended in that order. On edge I→I+u with u≠y add G_xy(I); with u=y add F(I) iff x∈I (else zero). The initializing edge is only once, so no overlap; when x=y no such edge can inject. For every possible z arc L→M add G_xy(L)B(M) to all t∉M through w suffix updates; if z already included then no such edge so no repeated-label error. This uses no dense matrix multiplication and beats the first strategy on wide ideal grids, e.g. width three O(n⁵) versus n⁶. Both algorithms include n⁴ output; choose smaller time to fit J,E,w. Arithmetic exact: each bridge term ≤ number E_full of linear extensions by injection concatenation, and for fixed inner labels all bridge terms sum ≤E_full, so even unscanned signed corner totals bounded by O(E_full), prefix scan intermediate magnitudes O(E_full). O(n log n) bits per count plus index representation.

Baseline comparisons: de Loof–De Meyer–De Baets 2006 https://doi.org/10.3233/FUN-2006-712-309 explicitly computes pair marginals on ideal lattice, not four. Simple same-input exact baseline runs counting DP separately for each ordered quadruple, filtering arcs that violate its three order constraints; O(n⁴ E) arithmetic. The old counting DP is cited in De Loof and Kangas et al. https://ijcai.org/proceedings/2016/92. Recent blocking-ideal work https://arxiv.org/abs/2501.11073 studies exact pair counts and special shapes, not the full four-way requested tensor at this model. Focused indexed check didn't locate exact four-way same-bound result; no live Google gate satisfied, no priority claim.
