# Independent scope and proof audit

The stale-slot model distinguishes fixed lists from adaptive choices over classical observations. The three-epoch formula requires adjacent totals at most the Shamir degree, the stated hidden refresh space, and a sufficiently large field for the upper construction. If a positive clean deficit exists, choose the middle sites to maximize the rank of the first refresh on that list. Conditioning removes that rank from the hidden refresh. In the reduced polynomial space, the first read set leaves an affine space of dimension at most the reduced degree minus the first set size plus the hidden refresh dimension. Greedy distinct evaluations then force an inconsistency when that dimension is too small. This lower bound does not depend on the final refresh. The upper construction checks surjectivity on each relevant quotient and unions the failure bounds; overlap of read sets is allowed.

The simulation argument requires a separately proven real implementation of the ideal functionality, in particular for adaptive exposures and any retained or correlated protocol state. It neither supplies a KEM nor proves an implemented key service secure. The Lean file proves the reversible transcript normalization, not the entropy or composition arguments.
