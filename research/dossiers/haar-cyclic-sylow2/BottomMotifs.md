# Imported marked metabelian input

This records the exact input used by the cyclic-abelianization branch of [the proof](Proof.md). It is a synopsis of the supporting classification, not its full verification bundle. In particular, this dossier does not re-establish the stable-mark cases, short-relation rank argument, or the exhaustive phase screens.

The supporting all-cyclic proof analyzes exactly the marked metabelian group $M$ plus a later abelian lift. Only its **bottom motifs in $M$** are used in the cyclic Sylow 2 argument. Every odd, even mixed, or repeated-mark branch supplies a literal equal-length barbell of length $m\le32$, with the exception of the two distinct-mark C3/F7 rows previously handled by a separate voltage argument. The new short exact check provides an equal-arm $m=8$ theta in both exceptional rows (rotation roots 2 and 4 modulo 7). The normal-form descriptions, mark rebases, and branch coverage are independent of the derived length upstairs.

For large cyclic abelianization order $n>1024$, the short-relation rank argument already constructs a literal barbell with $m\le32$ in $M$, starting with the metabelian dyadic cycle theorem. The powers-of-two order branch used pure $m=2n$ hub cycles. This already has $m\le32$ for $n\le16$, and $m=64$ for $n=32$. To keep the uniform bound small, the two new phase screens also check $n=32,64,\ldots,1024$. Every power-of-two mark passes a low-scalar chart when $t^2=\pm1$. For nonscalar $t^2$, among 510 marked orbits at those orders the generic screen fails at 12, eight of which are handled by the already established stable-mark cases $k=2,3,4$ valid for $n\ge27$. All four other exceptions have $n=32$, so the old $m=64$ pure-hub argument suffices there. Thus every cyclic case has a bottom barbell with $m\le64$ or an equal-arm $m=8$ theta.
