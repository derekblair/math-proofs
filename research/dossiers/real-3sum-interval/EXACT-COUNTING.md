# Counting arbitrary-real 3SUM by two ordered cuts

The weighted bracket algorithm in draft #72 can count exact triples with multiplicity (even per target) at the same asymptotic bound using two threshold cuts and zeroth-moment requests. Not a new reduction from a generic decision oracle. The decision-to-count literature is prior, e.g. Fischer–Jin–Xu arXiv:2410.20764 (deterministic integer setting), and Alman–VW arXiv:2610.06783 reports faster randomized bounds; no priority claim.

Tag all entries in sorted A and B as in the weighted decision proof, with distinct pair tags in (0,T), T an O(log n)-bit integer. Pairs with original sum c are exactly those lex sums below (c,T) but not below (c,0). For each ordered threshold q, count whole block rectangles whose maximum is below q by a monotone two-pointer pass over the block maxima; use prefix sums of B block sizes to add their cardinalities in constant time per row block. Rectangles with min<q≤max cross the cut; their column ranges are contiguous and both ends monotone, found by another pair of shared pointers on the maxima/minima. If both block indices increase strictly, the minimum rises above the earlier maximum, so two such rectangles cannot cross the same cut. Their index difference is injective and there are at most mA+mB−1 crossing rectangles. Others contribute zero. This statement covers exact ties and permits unequal last block lengths.

Run the source bracket routine (Chan–Itakura–Ma–Yu Lemmas 5.3/5.5) for both ordered thresholds in all crossing rectangles. A returned predecessor identifies its exact lex rank by one zeroth moment request on the whole row interval using weak inequality; this is exactly the count below q. Separation tags make original-real equality intervals unambiguous and the final rank independent of which unperturbed pair is returned. Total O(n²/d) queries and staircase work; all added zeroth-moment work covered by weighted s≤2 ledger. Output each target count, or sum counts over repeated target positions for total ordered triple count; counts ≤n³ fit word-sized arithmetic up to constant factors. Distinct positions in a single-list variant can be recovered by subtracting equal-index cases by elementary inclusion-exclusion in roughly linear time after sorting. No exclusive priority or all-model record asserted.

Lean Counts.lean verifies finite-set prefix differences and injective staircase index counting. check_cuts.py verified 20,500 exact duplicate-heavy per-target tests, using brute within blocks for independent model validation, not an end-to-end fast solver. An independent audit checked the bracket promises against Chan–Itakura–Ma–Yu §5. This is a direct application of their predecessor and rank interfaces, not a new generic reduction from an arbitrary decision oracle.
