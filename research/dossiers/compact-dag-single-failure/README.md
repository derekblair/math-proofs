# A fixed-pair single-failure oracle for compact quadratic DAGs

## Model and exact theorem
Input a signed DAG on n vertices represented by a list of nonempty complete bicliques h, each tail i carries a real degree-at-most-two polynomial p_hi, each head j a real coordinate x_hj and offset z_hj, and each represented copy i→j has cost p_hi(x_hj)+z_hj. The effective simple edge weight is minimum over copies, absent pairs +∞. Let M=Σ_h(|T_h|+|H_h|). Fixed s,t. In exact arithmetic and comparison RAM, deterministic Õ(n+M) preprocess and space, then O(1) exact distance query for deleting any one vertex, deleting any one ordered edge (all copies of the pair), or changing/inserting one forward edge to any supplied new finite weight. Supports negative weights, repeated coordinates, overlaps, ties, unreachable and terminal cases. A forward edge means an ordered pair whose tail precedes its head in the retained topological order. An explicit shortest path can be returned with linear time in its output length using stored witnesses. Not bit complexity, no general cyclic promise, no per-copy parallel deletion claim in this formulation. On M=Õ(n) inputs with Θ(n²) represented arcs, this takes Õ(n) rather than explicitly expanding Θ(n²) arcs or running a compact DAG relaxation for each of Θ(n) potential internal failures.

## Topological cut formulas
Obtain original topological order ρ in O(n+M) from virtual nodes T_h→block_h→H_h, then keep only original vertex order. The expanded support is acyclic iff this representation graph is; all tails of every block strictly precede all its heads. If empty blocks are supplied, discard them in time linear in their list overhead before applying the bound. Compute α_i=d(s,i), β_j=d(j,t) and original path witnesses by signed DAG DP. Let D=α_t. For deletions return +∞ if the original target is unreachable or if a failed vertex is s/t. The insertion formula below also applies when D=∞. If s=t, empty path unaffected by all other forward edge/vertex changes. For internal vertex rank r between ρ(s),ρ(t), the distance avoiding it equals min of c(i,j)=α_i+w(i,j)+β_j over edges ρ(i)<r<ρ(j). Any avoiding path crosses exactly once; its prefix and suffix are bounded by α,β, and conversely their optimal original witnesses cannot visit rank r by acyclicity. For deleted edge ordered pair (u,v), use r=ρ(v) and cut ρ(i)<r≤ρ(j), excluding pair (u,v). Both shortest prefix/suffix again cannot use that edge, since one lies on the left and the other entirely on the right. When a cut is not strictly between terminal ranks (edge r=ρ(t) is still active), the failure cannot affect a path; return D. Directed edges with rank tail≥head are absent in this DAG, so deletion no effect. Removing a non-edge has no effect via the same formula. Replacing/inserting one forward edge with weight a has distance min(delete_distance,α_u+a+β_v): paths using the changed pair once have original prefix/suffix excluding it, and acyclic concatenation is valid.

## Compact top-two certificate
Temporarily keep copies and calculate c_h(i,j)=α_i+p_hi(x_hj)+z_hj+β_j. Retain two lowest finite-cost distinct head endpoints for each tail in each block, and two lowest finite-cost distinct tail endpoints for each head, remembering original edge witnesses. For a cut, every nonempty block's admissible pairs are one full side × subset of the other (or both full), because all tails precede all heads. Thus if a single pair is excluded, a best survivor for each vertex of the subset side lies among its retained two. This certifies all cut minima at once and contains only O(M) arcs. Infinity inputs can be omitted. Deduplicate retained records by ordered pair choosing min score. This does not require retaining the best original copy of every pair; the preceding argument is already applied to each block before taking the global min across all copies. Dedup only preserves candidate minima. Each retained pair is active on rank interval [ρ(i)+1,ρ(j)−1] for vertex failures, [ρ(i)+1,ρ(j)] for edge cuts. Sweep all ranks in O((n+M)log(n+M)) with insertion/removal heap, storing best and second distinct pairs for each active cut, including witnesses. Same interval for all copies of a pair, so global dedup safe. Return first unless deleted pair is first, then second. Ties use any consistent choice; no lex-shortest claim.

## Exact soft-linear preprocessing

Write each polynomial as pᵢ(x)=c₀ᵢ+c₁ᵢx+c₂ᵢx² within its block. In the forward topological dynamic program, before any head is processed every tail distance αᵢ in that block is final. Build the points (c₁ᵢ,c₂ᵢ,c₀ᵢ+αᵢ) for its finite tails. At a head j, minimize the inner product against (xⱼ,xⱼ²,1), then add zⱼ. Minimize over all blocks containing that head (and retain the zero-length source case). In the reverse dynamic program, all βⱼ are final before accessing a block from any tail. Build the points (xⱼ,xⱼ²,zⱼ+βⱼ), and query at the tail with (c₁ᵢ,c₂ᵢ,1), adding c₀ᵢ. Ignore infinite offsets. Remember a winning block and the original endpoint to obtain predecessor/successor pointers.

Both searches use the same 3D linear-support primitive. In directions (a,b,1) the lower normal regions of the convex hull give a planar subdivision with linear size in the point count, by the linear face and edge complexity of a 3D convex polytope. Restrict the regions to a box containing the query pairs; point location returns a minimizing original ID. Use deterministic [3D convex hull construction](https://doi.org/10.1145/359423.359430) and [planar point location](https://doi.org/10.1137/0212002) for soft-linear build and logarithmic query time. A lower-dimensional hull can be handled directly in its affine span; choose any minimizer on boundaries and retain an original ID for duplicate points.

To get the best two **distinct IDs**, use an index segment tree with this primitive at each node. Find a first minimizer at the root, then query the O(log k) canonical subsets excluding its index (for a side of k endpoints), and keep the best survivor. Duplicate sites in separate subsets are not lost, even when both minimizing IDs have equal values. Each level stores a total of O(k) input points; building over logarithmically many levels costs soft-linear time and space. These forward/reverse queries simultaneously give the two winners required by the cut certificate: the remaining αᵢ or βⱼ is constant for a fixed querying endpoint and therefore does not change the ranking. The number of stored points and queries over all blocks, including their incidence lists, is soft-linear in n+M. The rank sweep likewise costs soft-linear time and space.

For a finite answer, concatenate the original predecessor path to the selected tail, the witnessed edge (or new changed edge), then the original successor path to t. The cut or topological order makes all these original path pieces admissible. The pointers recover the route in time proportional to its size (plus constant overhead), without searching for edges.

## Reverse-query equivalence
For arbitrary fixed-degree polynomial queries p_i and arbitrary head samples (x_j,z_j), recover all minima m_i=min_j(p_i(x_j)+z_j) from vertex-failure distances in a single construction of size O(I+J) in the same representation. Set chain s→a_1→f_1→a_2→...→f_I; charge −L each time entering a_i and 0 on arrows into f_i. All a_i have arcs to independent heads via one complete polynomial block; each head→t edge zero. Choose L>2*max absolute all possible scores via elementary global coefficient and coordinate bounds, without evaluating product. Then deleting f_i restricts exits to a_1..a_i. Latest reachable a_i strictly dominates so replacement distance equals m_i−iL (same for i=I). Each f_i for i<I lies on the unrestricted latest shortest path. For an edge-failure variant remove a_i→f_i. Signed graph is a DAG; if desired reweight nonnegative using explicitly bounded topological linear potential and subtract a common terminal offset. This establishes an equivalence up to linear/polylog overhead with batched reverse support, rather than promising an unrestricted 4D near-linear breakthrough.

## Antecedents and verification

[Lee–Lu](https://www.csie.ntu.edu.tw/~hil/paper/sidma14.pdf) give O(n+m) algorithms for both replacement versions in an explicitly listed DAG. Their m counts listed edges, whereas M here counts biclique incidences and may be asymptotically smaller. [Monge dense-distance graph methods](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.ICALP.2018.61) and [Monge submatrix querying](https://cs.runi.ac.il/~smozes/submatrix.pdf) are related implicit techniques for other structured classes. No global fastest or priority claim is made.

- `node compact-dag-single-failure-replay.js` checks exact integer instances against expanded-DAG recomputation: 1,400 instances, 17,500 vertex deletions, 123,900 edge deletions, and 123,900 finite edge changes or insertions. It tests the top-two certificate and the query formulas, not a geometric-backend implementation or a runtime benchmark.
- `CompactDagFailureCertificate.lean` checks five abstract finite certificate ingredients under Lean 4.34.1 with mathlib `d13f23b723b8a846827a245b89c10fc7d3f11612`. The DAG oracle, geometry, and running-time proof are not formalized.
