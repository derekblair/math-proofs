# Independent audit: group potential + SCC sweep

Pass, with inherited box-DP proof boundary. No unconditional linear exponent, no full Lean replay. State total time with input normalization O(m) additive if an arbitrarily long parallel-arc list is allowed. Use G=1 convention for the case of no active labels; k=0 is an immediate YES.

* A group's one-shortest-path tightness certifies all its own shortest arcs by the nonnegative slack sum. U contains an original shortest route per pair, hence own U distances equal originals; cross distances need not agree with ambient distances, and infinity is an absent label arrow. Breaking a negative augmented cycle into U walks plus marked reversed arcs is valid, including empty walks and parallel original/reverse arcs. Its compressed label walk has no higher weight. Conversely lifting a negative label cycle only needs a negative closed walk, not a disjoint or simple lift. The label normalization d_ij−d_jj has the right destination because the reversed arc at t_j returns to s_j.
* Bellman–Ford operates on finitely many vertices and finite formal signed weights, with supersource; a strict addition/comparison-only interface can represent x−y by (x,y), add componentwise and compare via cross-addition. No sign oracle beyond comparisons, division, or bounded-bit fiction needed. The box averaging levels are existential, and rank cuts use only coordinate comparisons. Precompute admissibility across all 2^k subsets before O(3^k) partition DP (or test selected masks at the cost absorbed here). Labeled arcs after normalization O(kn²); k≤n after duplicate terminal rejection.
* The grouped box proof uses g−1 coordinates but still k paths; the two nondecreasing own coordinates and exact span W+2W remain true with reused group label. Accordingly cap 18k(g−1) and state exponent O(kg), not O(g²). For g=1 all relevant arcs strictly advance one common potential. Same argument works for SCC induced restrictions since it needs feasibility and tightness, not completeness of the local arc sets.
* Exact SCC invariant: position of each label summarizes the head of its only selected arc into the future (or the unused initial source), or DONE. Once a component is passed nobody can use any of its vertices again. Future entries from the same prior prefix and different SCCs can later share a component; the still-pending coordinates therefore must not be dropped. Every entry and chosen exit tail is used by the same local label; crossing edges hence add no resources beyond endpoints. Incomplete states whose required terminal lies in an already skipped SCC can never pass all-DONE; harmless proactive rejection. No moving completed tokens and no path with revisited component. The s=t singleton uses/blocks its terminal; no local label arc required. For duplicate terminals of distinct labels reject. Multiple local arrivals at the same vertex cannot both pass a local mask/box solution. Each complete path follows original D_i and therefore telescopes; induced and trimmed arc sets must keep original labels.
* In the trimmed cutoff, first reject any admitted transition with no restricted x_i–y_i route; a valid x_i=y_i has zero distance and trivial path. Original individual tight feasible source potentials remain available globally (capped at d(s_i,t_i) if needed). Their telescoping lower bound on every other arc proves the local restricted routes are shortest in the trimmed union. Moreover every trimmed arc is on a local shortest route, and every union-shortest route for those endpoints has zero slack in that original potential. Group-characterization reduction is valid; never let it change label routing. Restricting any group certificate from all labels in the entire C gives a certificate after selecting admitted labels and trimming all supports; γ≤g_C for nonempty active components, with 1 convention for trivial/empty groups. Computing trimmed g to enforce cap takes ≤3^k poly(n) per transition. Use stage cutoffs starting at 1; minimum cap realized by some YES solution gives the stated YES-only running time, but earlier negative restricted stages are NOT general NO certificates. All-NO recognition must finish an unrestricted stage/bound.
* Sublocal masks witness disjoint routes by disjoint vertex sets, even if masks overcount a route and unused vertices remain; sum over all (chosen, prior occupancy) disjoint masks gives 3^|C| per label. At arbitrary C with |C|=1 and p=0/1 interpret the |C| exponent with poly(n) overhead; all globals O(n^k) pending states times n^{O(k)} guesses and polynomial SCC count.
* Complete pair-gadget source/sink directions prevent traversing multiple gadgets. Simultaneous pair conflict yields global g=k yet each gadget SCC has two active labels and g_C=2; private direct alternatives achieve disjointness. This is not evidence that all graphs have local G bounded or all NO instances have cheap witnesses.
* Exact replay in current checkout: grouping 959 subset equivalences and potential checks. SCC 345 instances, 1091 candidate transitions, 845 singleton fragments, 1378 pending skips. These scripts do not independently implement the geometric local solver or cover arbitrary real bit behavior, nor is that claimed.

Primary scope: https://arxiv.org/html/2611.34013v1 Question 11.1 explicitly asks polynomial exponent and possibly linear exponent for arbitrary positive weights. The DAG token component is classical, as the source acknowledges; negative cycles and subset partition DP are standard. The defensible extension is the new group-sensitive and SCC-local exponents using the geometric box bound, not priority for those primitives or another general solution to Question 11.1.
