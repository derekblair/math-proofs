# SCC-local common-potential acceleration

**Result.** Let U be the union of all original source–target shortest-path DAGs (D_i), and for each strongly connected component C let g_C be the minimum group count for tight potentials on the restricted DAGs D_i[C], with each potential feasible on U[C]. Only labels with nonempty D_i[C] need grouping; isolated participants may be assigned arbitrarily, and write G=max(1,max_C g_C). Then deterministic directed k-DSP on positive real weights takes n^{O(kG)} time on the source addition/comparison model. Allow an additive O(m) input pass if parallel arcs are supplied explicitly; heavier parallel arcs are discarded and equal arcs can use a common representative. For k=0 return YES. This can improve the global grouping bound to n^{O(k)} even if global group count is k. Also, independently of grouping, if each C has O(k log n) vertices then n^{O(k)} suffices.

## Sweep invariant and endpoint cases

Compute a topological order of U's SCC condensation. In a DP layer before one SCC, state x_i is the next vertex on path i not yet processed, or DONE. Initially x_i=s_i for all i, including s_i=t_i. The state's witness comprises disjoint prefixes inside processed SCCs and their selected last outgoing arc, when any, terminating at x_i in an unprocessed SCC; for newly unstarted commodities there is no incoming arc at s_i. A stored next-entry coordinate refers to a global vertex, so an outgoing arc may skip any number of intervening SCCs. Edges on a fixed shortest path strictly increase its original source distance and SCC visits cannot repeat because the condensation is a DAG. Consequently a chosen route has exactly one contiguous (possibly singleton) fragment in each component that it visits.

In component C, the admitted labels are exactly those whose x_i lies in C. For each admitted i, if t_i∈C choose y_i=t_i and mark DONE, since it could never return after leaving. Otherwise independently choose an exit arc (y_i,z_i)∈D_i with tail in C and head in a later SCC, and set the successor x_i=z_i. All other coordinates stay unchanged. Reject duplicate prescribed vertices between different commodities among the local x_i,y_i and all pending coordinates; in particular later collisions at an already pending source are rejected. An x_i=y_i is permitted and denotes a compulsory local singleton. No label may consume a terminal of any other label that has to be used: if the terminal is in C and not currently admitted because its path skipped or is not yet at C, that state cannot be completed through its required terminal. One can proactively reject such states, or let the final DONE test and the spatial constraints enforce it. All other terminal and cross-arc issues are ordinary disjointness constraints. The cut arcs only contribute their endpoints to the respective SCCs; sharing a cut arc would imply duplicate endpoints and is rejected. At most n^{O(k)} entry/output guesses per all state/transition layers, inclusive of arc IDs after heavier-parallel normalization.

Test whether the admitted restricted D_i[C] have disjoint fragments x_i→y_i. Parent states don't need pairing metadata or old arc IDs once their contribution is certified. Distinct components have disjoint vertex sets, local fragments ensure endpoint disjointness inside their component, and selected exits connect successive route fragments. A successful all-DONE state yields exactly original shortest paths, because every chosen arc is in its original D_i, so summing telescopes to original d(s_i,t_i). Conversely any solution uniquely provides its next-entry coordinates and cut arcs and passes every local test. No recomputation of shortest DAGs on changed endpoints is necessary or allowed if it would introduce unlabelled arcs.

## Local solvers and tighter parameters

1. Use the common-tight-potential box solver for admitted labels only. Feasibility uses original U[C] arcs plus reverse copies of requested restricted arcs with negated weights; all potentials finite via a zero-weight supersource and exact Bellman–Ford. It does not rely on the global terminal distance formula for these initially restricted arcs. Empty local support is permitted exactly when the admitted endpoints agree. A partition of all active C labels restricts to a group partition for admitted labels. Thus if p labels enter C, local runtime ≤poly(n) |C|^{O(p max(1,g_C))}; computing an all-label partition once per C costs 3^k poly(n), absorbed by global n^{O(k)}. First reject any admitted transition with no restricted x_i→y_i route. Then trim each admitted D_i[C] to arcs on an x_i→y_i route and recompute g for just these p labels. All remaining labelled routes have weight φ_i(y_i)−φ_i(x_i) in the original source potential, so each is a shortest x_i→y_i path even in their trimmed union: every arc in that union is dominated by φ_i's original feasible edge increments, a path lower bound via telescoping. The local assignment characterization therefore applies on this trimmed union with new literal endpoints. Its group number can only decrease. A stage with cutoff γ skips local transitions whose trimmed grouping cannot be achieved in γ groups; if a solution has all transitions under cutoff, it succeeds. Iterating cutoffs starting at 1 gives a YES-witness-dependent running time n^{O(kγ)} for minimum such maximum local grouping γ; NO recognition must still use the unrestricted bound. Grouping does not alter the label-specific edge sets used by the local solver.
2. Independent exact small-C fallback: for all vertex masks S⊆C, and every admitted i, compute whether x_i→y_i is reachable in restricted D_i[C][S]. Partition via subset DP: for each i choose any feasible mask disjoint from previous chosen masks; evaluating all current mask/submask choices costs O(3^{|C|}) per i, and unused vertices are allowed. Overchosen masks do not hurt correctness; a solution can use exactly its occupied masks. Runtime O(p 3^{|C|} poly(|C|)). This gives n^{O(k)} whenever all SCCs are O(k log n) in size, even with unbounded g_C. Simultaneous grouping and small-SCC controls can be mixed across components, with overall n^{O(k)} times the maximum over components of the better local time bound. At a viable transition p≤min(k,|C|), by entry disjointness.
3. Global grouping is not essential even for the extreme pair-gadget construction. Every pair conflict x↔y forms its own two-vertex SCC, involving only two labels. All other SCCs are singletons. Thus for H=K_k the global chromatic grouping k coexists with local G=2. The result is not a worst-case linear exponent guarantee: no bound of constant G or small SCCs is asserted. Adjacent SCC transitions cannot be replaced by arbitrary local shortest paths on U unless the path's original commodity restriction remains enforced.

Replay `python scc_check.py`: independently compares SCC sweep plus the subset-mask fragment verifier against exhaustive original shortest-path tuples on small directed positive-integer instances, checks group counts on complete pair gadgets, and includes multi-component SCC fixtures with skip exits, local singleton fragments, and globally colliding source/target use. This does not replay the full geometric local solver, whose proof is imported unchanged from the box algorithm.

## Orthogonal local solver: used shared-support vertices

The [shared-visit quota solver](shared-budget/SHARED-BUDGET.md) is exact for a given
local quota (b), with (2^{O(b)}) polynomial postprocessing per transition. An
independent inclusion–exclusion sieve counts disjoint tuples in (2^r) times a
polynomial using polynomial space, where (r) counts shared vertices in the
trimmed admitted supports. This improves the old local (3^{|C|}) mask solver
without requiring common tight potentials. The [cyclic obstruction](shared-budget/CYCLIC-TRIM-BARRIER.md)
shows that even on YES witnesses, tight-potential grouping can be large in a
single giant SCC although the minimum shared-visit quota is zero. The
reverse separation is included. Neither observation establishes a uniform
linear exponent or a runtime lower bound.
