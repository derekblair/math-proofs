# Independent shared-budget and cyclic trimming audit

Pass both scoped paper results. No unrestricted linear exponent, no runtime lower bound.

1. Color-DP soundness: per label topological propagation appends only labelled edges, charges every actual shared occurrence on entering a vertex including the source, with no double-charge for an s=t source/sink. Private vertices cannot collide across labels by construction. One color globally cannot be used twice, including collisions along different paths. Distinct shared vertices colliding in color create a false negative for that coloring alone, not after taking the full family: injectivity on each size≤b distinct set follows by extending it to size b. For b=0 or r=0 use reachability after deleting B; immediate if k=0. Different labels sharing compulsory terminals are correctly rejected (or may be rejected earlier); s=t reserves/uses its vertex. Reject disconnected requested pairs before constructing DAG supports so infinity never enters finite tightness tests. Counting original occurrences, not distinct visited vertices before gating, is essential.
2. Exact sieve: fix a tuple with j occurrences within B and a dummy set F of size r−j; the alternating sum is one iff the union of its actual vertices with F is B. With r total occurrences including dummies, a union of size r cannot contain any repeated shared occurrence or filler overlap. Thus each valid tuple contributes exactly once, and invalid ones vanish. Convention binom(a,d)=0 when d<0 or d>a; clamp b≤r. All sums exact integers; a residue of zero (even many small moduli whose product has not exceeded a proven bound) is not a NO certificate. |Q_S|≤2^(sum_i |V_i|) for simple per-label DAGs as a path's vertices specify its unique increasing order in a fixed topological order; the weighted and signed intermediates add at most O(r+log(b+1)) bits. Recomputing each S with coefficient arrays is polynomial working space, and multiplied binomials and exact signed addition are polynomial bit-time.
3. The time for arbitrary positive real weights is after preprocessing with input-weight addition/comparison, not Turing bit-time on arbitrary reals. Once the DAGs are given, quota/count postprocessing can have ordinary bit bounds; bit-mask operations add only polynomial overhead. Include original arc-input read cost. For path tuple counting, normalization counts **vertex-path tuples**; distinct original minimum-weight parallel-arc identities are not counted separately. If counting edge-ID paths instead, keep multiplicities and increase the path-count bit bound (log count ≤ O(L log L) still suffices). Heavier parallel arcs cannot belong to shortest routes.
4. In the SCC sweep admitted labels only, remove arcs and vertices not on a restricted x_i→y_i fragment using two reachability searches, reject missing paths, and retain x_i=y_i singleton vertices. B at each transition is relative to its fixed endpoint trimmed supports, including terminals and singleton visits; replacing those D_i by unlabeled shortest-path choices is wrong. Joining local witnesses is exact with the inherited SCC state: exit identity connects its tail to the chosen next entry, no vertex can be revisited after processing its component. n^{O(k)}·2^{O(b)} decides exact uniform local quota (negative answers exclude only that quota). The 2^r bit-time sieve is local after trimming; r≤|C|.
5. Barrier: each H transit costs ≥8; avoiding H takes either direct same-label weight8 or petal strict-index drop weight4. Multiple transits cost ≥9, and sources/sinks cannot be internal. Thus non-own a/b ports never occur in original shortest routes and connector must use its private path in *every* disjoint solution. Opposed unit arcs in each petal remain tight demands after every solution's actual endpoint trimming, although the direct-routes solution never visits a shared vertex under the admitted-only local definition. Clones preserve that fact and create disjoint 2-cycles, giving genuinely arbitrarily large C at fixed k. Do not advertise zero quota for original global untrimmed B (connector alternatives touch all ports), nor any algorithmic lower bound from the forced group count.
