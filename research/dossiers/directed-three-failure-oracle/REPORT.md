# Batched elimination for cubic deterministic directed three-fault replacement paths

Independent proof of the bound **announced without proof** by [Harada–Terao arXiv:2611.29061v1, §4](https://arxiv.org/html/2611.29061v1); the proved Theorem 2 bound in that version is O(n³ log n). No priority or faster-than-announced claim. The graph is simple and directed, with arbitrary finite real edge weights and no negative cycles. Exact real operations are addition, subtraction and comparison, at unit cost; indices are O(log n)-bit words. The only imported improvement is a deterministic O(k^α) exact real APSP algorithm for some fixed 2<α<3; e.g. [Essayag–Zabokritskiy arXiv:2611.17215v3, Theorem 1.1](https://arxiv.org/html/2611.17215v3). Their earlier-rectangular-bound alternative already suffices.

## Ordered shortcut invariant

Use the shortcut states of Harada–Terao. A shortcut u to v in state X is a nonempty walk with no internal X vertices; its tag is its first original edge e. Keep the f+1 best distinct tags for every ordered pair (u,v) by the lex tuple of weight, original hop count, global edge ID, with each tag stored at its true optimal (weight,hops). Missing tags are just omitted. Initially X=V, and every shortcut is one edge. Hops give a well-defined secondary minimum, excluding gratuitous zero cycles. Shortcuts may repeat vertices before minimization, but removing a repeated interior vertex preserves the tag. Nonempty u-to-u shortcuts are harmless; the auxiliary construction handles them even when used for an invariant only.

For any F of at most f failed edges with tails in X, the distance including its hop tiebreak equals the lex distance in the sparsified X-shortcut graph after deleting the failed tags. Decompose an optimal original walk at its X vertices; any segment whose tag was omitted can be replaced by an equal-or-better retained tag, at least one of the f+1 survives. A surviving shortcut cannot use another failed edge because all later tails are outside X. Conversely concatenation realizes any surviving shortcut walk in the original graph. This is Lemmas 8–10 of the source with the lex weights. An optimal surviving walk is simple for distinct terminals because removing a cycle never increases weight and strictly reduces hops when weights tie.

## Batch X to Y

Let k=|X| and Z=X\\Y. For any true top f+1 tag e of a Y-shortcut u→v, split an optimal such walk at its X vertices. Its first X-shortcut from u has destination w in Z or w=v. Its tag e must be among the stored f+1 tags of that pair (u,w). Otherwise replace the first segment by each strictly better distinct tag in that list and append the same suffix (all internal X vertices are in Z); this gives f+1 tags strictly better for u→v, contradiction. Ties in weight/hops break by globally fixed tag order, which is preserved when the same suffix is added. Every later segment leaves a vertex in Z; that tail has no failed edges in the child state and the tag does not affect u's tag. Thus collapse every later pair to the best untagged (weight,hops) shortcut. Every walk considered by this restricted construction is realizable in the underlying graph and the construction finds the true minima for each globally best tag, not just approximately good tags.

Only O_f(k²) distinct tag IDs are present in the parent lists. Sort and replace them by local order-preserving integer codes, keeping a dictionary to global IDs. For each subset of at most f bit positions of those local codes, and each assignment on those positions, create one mask set of allowed tags. Include the empty mask. The family has O_f(log^f(2+k)) masks. For each one, build an O(k)-vertex auxiliary digraph: two copies of each u in Y, one source-only and one sink-only, and ordinary interior vertices Z. First arcs from any source-only u to w in Z or sink v use the lightest permitted parent tagged shortcut for (u,w), ordering weight then hops then local tag ordinal. Other arcs from Z to Z or sink use the lightest untagged lex (weight,hops) parent shortcut. Omit unnecessary interior self-loops. No cycles involve sources or sinks. A cycle in Z expands to a closed walk in the original graph, so is nonnegative in weight; in case of zero weight its hop count is positive. Run the exact tuple APSP routine below on this auxiliary graph, with tag ID and first destination ID in extra coordinates on first arcs only, zero elsewhere. Read the winning pair and tag from every ordered source–sink output. Retain f+1 smallest distinct reported tags for each pair, with cheapest report per tag.

Every required e is returned by at least one such mask: for each of the at most f tags better than e at u→v in the restricted construction, pick one distinguishing bit of its local code, and fix those bits to e. The mask excludes all better tags and includes e, so e wins together with its exact optimum weight/hops. Other returned tags never underestimate true values. Since all true top tags are found exactly and no incorrect value can outrank them, final truncation reproduces the invariant. Construction overhead per mask is O_f(k²), and comparison of outputs against constant-size accepted lists costs O_f(k²). Child creation therefore takes O_f(k^α log^f(2+k)) time.

## Exact tuple APSP, no numerical infinitesimal or real multiplication

Store a tuple of fixed length as separate exact real cells. All coordinates of its additions, subtractions and copies are computed individually; comparison is lex, so overhead is constant per operation. Small integer IDs and hop counts can be embedded as reals by adding the fixed real constant 1 in increasing index order; generated hop counts can remain in exact real cells, where their bit length is irrelevant. For correctness of emulating a comparison-add/subtraction algorithm, interpret tuple (a0,a1,...) mathematically as a0+a1 t+... at a real parameter t>0. The implementation does not ever construct or choose t. For every fixed finite sequence of the arithmetic and comparisons, all real cells are fixed-degree polynomial forms, and each comparison outcome for the tuple agrees with all sufficiently small t, by its first nonzero coefficient. Any purported execution exceeding the base algorithm's uniform worst-case bound would have a finite prefix exceeding it, which would also occur on a sufficiently small positive-t instance. The instance is valid: no cycle uses tag/destination arcs, and all interiors have originally nonnegative cycles with secondary hop sum positive if weight zero. This proves the running time without assuming an infinitesimal primitive. For the actual finite execution, there is an interval of tiny t realizing the trace. On a possibly smaller interval the correct distance polynomial is the lex minimum over the finitely many simple auxiliary paths. As the base output agrees on that entire interval, equality of polynomial coefficients proves the exact tuple answer. Integer address/arithmetic portions of the APSP algorithm are unchanged because they depend on comparison outcomes, not conversion of arbitrary real cells.

## Witnesses and explicit adaptive failure enumeration

For each batch, also run an unmasked split APSP with a duplicate source-only copy of each interior vertex z and the same sinks Y, no tagged source arcs needed. In its first arcs use first-destination ID as the last coordinate. All later arcs have zero in that coordinate, so each finite suffix from z to sink v returns its first destination w and optimal (weight,hops). Underlying chosen untagged arcs have known parent shortcut pointers and positive original hop counts, so following such next hops strictly decreases the hop coordinate for fixed v (even when weights tie); no cycle in suffix pointers. Store a binary concat pointer for following one parent shortcut z→w then the stored suffix w→v. If w=v, reuse the parent pointer directly. In the masked products, first tag and first destination together locate the unique original parent list entry and hence its path pointer. Concatenate to the precomputed suffix if the destination is interior, otherwise reuse the pointer. Concatenation nodes have exactly two nonempty children; no unary cost carried through levels. This stores O(k²) persistent pointers per child, and uses one extra O(k^α) APSP. Original leaf pointers are single edges.

The final shortcut query on O_f(1) vertices/tag nodes chooses minimum (weight,hops) using the lex semiring; witness expansion gives a simple source–target path in G\\F of at most n−1 edges. Binary pointers expand to it in O(n) work, including when subpaths are stored at shared nodes. For 3FRP enumerate a tree of failure sets: at each of the O(n²) nodes with fewer than three failures, get one lex shortest surviving path (or terminate unreachable state), then add each of its edges as one next failure. If an edge not on the chosen path fails, the path stays feasible with unchanged value, so this implicit enumeration answers all up-to-three failure sets as in the source; there are O(n³) recorded branches, O(n²) expansions at O(n) each. The preprocessing itself supplies the O(1) general distance oracle for every valid arbitrary failure set. This is not the task of explicitly listing every triple in E³, which may be much larger. The same three-slot construction gives constant-time oracles for two failures with one fixed source (fixed root s; three slots for variable target t and up to two failed tails) and one failure with both endpoints variable (no fixed roots; three slots for s, t and one failed tail). Each explicit reporting bound is O(n³): process each target for two-failure single-source, or each ordered pair for one-failure all-pairs, with the corresponding shallower failure tree and O(n)-time witnesses.

## Recurrence and storage

Pad n to a power of two N=Θ(n) using isolated vertices. At level j, each state is the union of the fixed terminals and at most f dyadic blocks of N/2^j vertices. There are at most O_f(2^{fj}) states, each refinement computed from its parent. For f=3, total time is
    O(N² + sum_{j=0}^{log N−1} 2^{3j}(N/2^j)^α log³(2+N/2^j))
      = O(N³ * sum_{d>=1} 2^{−(3−α)d}(1+d)³)
      = O(N³).
Local remapping is essential here; using original global tag bits at every level would leave an extraneous factor polylog N. Total stored graphs and binary pointers over all levels cost O(N³), since at level j they cost O(2^{3j}(N/2^j)²). One large APSP call can have at most its O(k^α) allocated cells in the stated model, reusable across masks and states. For leaf lookup sort failed-tail IDs and fill absent slots by repetitions (zero-failure fixed terminal case can explicitly request the trivial leaf padded by one terminal, or handle it separately). Indexing a constant-size tuple costs constant word operations, or use three nested directly addressed arrays to avoid requiring word multiplication. All f=3 requested distance answers are exact.

First differential control check.py uses independent full tagged elimination and compares 1,200 batched states (including negative individual weights, built by random potentials with zero cycles and ties) and 6,597 ordered lists. Its cubic Floyd kernel is a testing stand-in for the imported real APSP engine. Further path/failure controls are separate. No remote writes or model substitutions.

## Implementation-model audit and exact witness controls

Essayag–Zabokritskiy's §1 and §2.2 expressly define all operations on real cells as addition, subtraction, and comparison. This covers the fallback direct products. In particular §2.3 already computes the finite replacement sentinel from absolute value (sign test and subtraction), comparison, and binary doubling; reachability is returned via its ordinary sentinel comparison. The integer-only pieces run on ranks, sign/comparison outcomes, and bounded integer matrices, not floor/casts of arbitrary real inputs. In our simulation the returned code coordinate is an exact real cell; decode its discrete local tag/destination using binary search in the exact-real replicas of the integer code list in O(log k) comparisons each, not a real-to-word cast. This adds O(k² log k) per mask, absorbed by the stated α>2. An unreachable split source–sink pair produces the unreachable marker and contributes no candidate; an unreachable failure query terminates its enumeration subtree because further removals cannot restore a path. Equal source and target is the zero-edge, zero-weight answer. Distinct failed edges may have the same tail (duplicate tails in lookup only), and a repeated deletion of the same edge is equivalent to the set deletion.

The imported APSP kernel already charges bit cost for its own integer/address operations. The cubic global result uses unit operations on Θ(log n)-bit index words for comparing tags, addressing shortcut tables and writing records, plus unit exact real additions/comparisons; this is the ordinary interpretation of Harada–Terao's constant-time query and Theta(n³) output-size statement, not a claim of cubic bit-serialization under a model charging every word-address access/output by bits. At batch scale the few ID manipulations can also pay logarithmic factors in k inside the subcubic margin, though the persistent global pointers and indexed query/output operations use the stated word model. Current candidate theorem is distance-oracle plus explicit adaptive failure responses, with O(n³) real cells/words of storage and O(n) witness expansion.

witness.py tests two successive batch changes, split-vertex first destination reconstruction, stored parent paths, and then checks every returned witness has no failed edge, no repeated vertex, correct original hop count and exact weight. 9,800 exact randomized failure queries include 2,511 distinct failures with repeated tails, 1,981 unreachable queries and 717 zero-distance witnesses. The verification kernel is small-instance Floyd; it tests the reduction/witness mechanics, not the exponent of the imported APSP routine.
