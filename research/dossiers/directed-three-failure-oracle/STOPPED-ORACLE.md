# Stopped-tree exact directed three-failure distance oracle

Fix s,t in a simple directed graph on n vertices with arbitrary finite real edge weights and no negative cycles. Queries specify a set F of at most three distinct failed edges, whose tails need not be distinct. For 1<=b<=n and any available deterministic exact real APSP exponent 2<alpha<3 in the comparison/addition/subtraction model, the batched shortcut method in REPORT.md yields a distance oracle with
- preprocessing O(n³ b^(alpha−3) log³(2+b) + n^alpha);
- persistent storage O(n³/b) words/real cells;
- worst-case query time O(b²) using O(b²) temporary storage, or O(b) scratch by scanning cached rows directly.

The integer model is word-indexed with O(log n)-bit indices as in the dossier for cubic 3FRP. Output is one exact distance (possibly infinity), not an enumeration of every failure triple. The preprocessing bound includes global potentials; it also dominates their cost for b<=n.

## Construction and correctness

Pad n to N=Theta(n), a power of two, with isolated vertices. Round b to a dyadic block size B between b and 2b, stopping at the root if appropriate; asymptotic bounds are unchanged. Build the same three-slot dyadic state tree, but stop at block size B. A stored graph for a terminal union X keeps the four best distinct first-edge tags per ordered pair, to handle three failures, and contains at most three B-blocks plus s,t. Do not need tagged path witnesses or parent links in this variant; retain only the leaf graphs after preprocessing. When queried, identify the block for each failed tail, sort the at most three block indices and fill unused slots by repetitions of a present block (any fixed block if none fail). Use direct word-indexed path/table addressing to retrieve that state in O(1). The chosen X includes every failed tail and both terminals.

Before queries, use the standard shortest-path potential (also used by Weimann–Yuster) and compute once the shortest distances p(v) from a temporary super-source joined by zero edges to all original vertices, in O(n^alpha) time using the same APSP kernel. This augmented graph has no new cycles and all p(v) are finite, including originally unreachable vertices. They satisfy p(v)<=p(u)+w(u,v) on all original edges. Every stored tag of real shortcut weight d from u to v expands to a true walk, giving p(v)<=p(u)+d by telescoping; the real reweighted value d+p(u)−p(v) is thus nonnegative. This remains true after arbitrary deletions, since only arcs are removed. Discard failed tags and collapse each pair to its cheapest surviving shortcut; a minimum survivor costs O(1) to find among four candidates. Exact lex Dijkstra with (reweighted value, original hops) also works, but the distance-only oracle needs only the real first coordinate. Dense label scanning and cached row selection take O(|X|²) time. Convert the final finite distance d' back by d'−p(s)+p(t); return infinity if t is unreachable. If s=t return 0 directly. REPORT.md's shortcut sparsification lemma gives equality with the original failure distance on any state containing the failed tails. If potentials are not precomputed, a dense Bellman–Ford query takes O(|X|³) instead.

## Recurrence, working memory, and fast small-tail tier

At a level with component size k between B and N, there are O((N/k)^3) states and state transitions, and each parent has O(k) vertices. The certified batch cost is O(k^alpha log³(2+k)); sum over k=2^d B to get O(N³ B^(alpha−3) log³(2+B)), since sum_{d>=0}2^{−d(3−alpha)}(1+d)^3 converges. Leaf space is at most O((N/B)^3 B²)=O(N³/B). DFS traversal needs only O(n²) extra persistent live shortcut words on its ancestor stack (geometric squares); the largest APSP scratch allocation is bounded by its runtime O(n^alpha) in ordinary addressed memory, reusable within batches and global potential computation. Thus O(n³/b) is persistent storage, not a claim of that peak including every imported kernel's scratch. At b=1 this gives the constant-query cubic preprocessing endpoint; at b=n the actual stopped-state batching is empty, though this stated upper bound remains valid.

Optional: build a separate full-depth tree with two *tail slots* but still store four tags per pair. Distinct edge failures are not bounded by the number of slots; only their distinct tails are. This gives O(1)-time queries whenever at most two distinct tails fail, including three failures that repeat a tail. Its preprocessing is O(n^alpha log³(2+n)) by summing 2^{2j}(n/2^j)^alpha log³(2+n/2^j) from the root; its persistent leaf space is O(n²). Both are absorbed by the stopped-tree bounds: writing t=n/b>=1, log(2+n) <= O(log(2+b)(1+log t)) and (1+log t)^3=O(t^(3−alpha)).

The fixed-source and all-pairs variants use the same total of three slots: one fixed source plus variable target and at most two failed tails, or both variable endpoints plus at most one failed tail. No three-failure arbitrary-endpoint bound is claimed.

## Comparable primary results and limits

[Harada–Terao v1, Lemma 14 and §4](https://arxiv.org/html/2611.29061v1) provide the same-model constant-query O(n³ log n) preprocessing oracle for fixed s,t and up to three failures, and announce cubic fixed-terminal reporting without its proof. Their repeated single-vertex removal can be stopped at B to produce the same space/query geometry, but its preprocessing ledger O(n³(1+log(n/B))) does not yield the polynomial savings for intermediate B given by batching. We did not find a stated stopped-tree bound in v1.

[Weimann–Yuster, Theorem 1.1](https://www.cs.haifa.ac.il/~oren/Publications/replacement.pdf) is a genuine directed real-weight multi-failure comparison, but it is randomized and supports any endpoint pair. Its main real case has O(n^(4−a)) preprocessing, Õ(n^(3−a)) size, and Õ(n^(2−2(1−a)/f)) query (parameter 0<a<1); it does not dominate the joint fixed-terminal guarantee here. Even using modern real APSP in its all-pairs-subgraph preprocessing gives Õ(n^(alpha+1−a)) rather than the stopped-bound profile for equal query exponent. [Duan–Pettie](https://web.eecs.umich.edu/~pettie/papers/dual-failure.pdf) handles only up to two failures, and [Duan–Ren](https://arxiv.org/abs/2111.03360) is undirected. Integer-bounded, approximate, planar and random algorithms are not used as same-model deterministic comparators. This is not a claim that every point is optimal or that no stronger unpublished or specialized technique exists. For near-quadratic query allowance ordinary graph search may beat it in preprocessing, and for sparse inputs one can always take the minimum with direct sparse SSSP per query.

stopped.py implements exact integer-scaled tests of actual ancestor-to-leaf state selection and caching, super-source potentials and dense Dijkstra, checked against Floyd after deleting queried edges. It uses lazily populated small test leaves and Floyd in place of the accelerated engine; it does not benchmark preprocessing.
