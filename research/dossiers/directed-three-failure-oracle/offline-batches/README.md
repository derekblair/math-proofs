# Adaptive offline batches of exact directed three-failure distances

For a simple directed graph on n vertices with arbitrary finite real weights and no negative cycles, fixed terminals s,t, and a supplied batch of q queries each deleting at most three original edges, compute their exact distances deterministically in
    Õ(n^alpha max(1,(q/n)^sigma) + q),   for q<=n³,
    O(n³+q),                             otherwise,
where 2<alpha<3 is any available deterministic exact real APSP exponent and sigma=(3−alpha)/2. The first bound may always be capped by the full cubic construction plus writing q answers. This is offline and distance-only; not an unrestricted subcubic full-enumeration result. Arithmetic on arbitrary real cells is exact comparison/addition/subtraction; O(log(n+q))-bit word indices, as in the [adjacent batched dossier](../REPORT.md). For absolute concrete alpha see [Essayag–Zabokritskiy, arXiv:2611.17215v3, Theorem 1.1](https://arxiv.org/html/2611.17215v3), alpha=2.9929729. Then for q=n² the displayed power is 2.99648645, and for q=O(n) it is alpha. The sparsity advantage is parameterized by specified queries, not by graph edge count.

## Primitive and routing

Use the [batched shortcut lemma](../REPORT.md). A state X containing s,t and all failure tails for its queries keeps each ordered pair's four cheapest distinct first-edge tags. From any parent state on K vertices, one may eliminate any subset while preserving exactly this state invariant in O(K^alpha log³(2+K)) time. A tag bank gives exact distances under a query when the state contains all failed tails. Original edge IDs survive all relabellings. Compute one global feasible potential by exact super-source APSP, O(n^alpha), and reuse it for all shortcut arcs. The potential applies to every walk represented by a shortcut and makes a dense distance query on r vertices cost O(r²) by Dijkstra, even though the input might have negative real edges. If the input is already nonnegative or has supplied feasible potential, the potential cost is absent. One can also use O(nm) Bellman–Ford for the global potential or simply choose independent queries when advantageous. No nonnegative promise is imposed on the theorem.

A macro run begins with a valid state on N vertices (up to factor-two isolated padding) and q queries attached, gives three dyadic address slots to each query's sorted distinct tails, and fills unused slots by repetition (use s for an empty set). A level j node fixes one block per slot, each of width k=N/2^j, so its state consists of the union of these blocks and s,t, O(k) vertices. Only occupied children (at most 8) are constructed. Fixed terminals are not duplicated and do not increase slot occupancy. This is the same dyadic universe as Harada–Terao; a node is identified by its **ordered labelled** slot triple. Distinct state vertices may overlap across nodes but labelled addresses do not, which is important in the Kraft count. All node states contain every required tail for their attached queries; child unions are subsets of the parent union. A node can compute its actual needed count r_v=|{s,t}∪⋃ tails of its q_v attached queries| without touching real weights.

## Stop, trim, and restart

Fix a sufficiently small universal beta>0 (depending on alpha), and choose c=beta/10. At a node v:
1. If k=1, use the constant-size graph and emit all assigned answers.
2. If q_v*r_v² <= k^alpha, one batch eliminates to the actual needed vertices. Answer the attached queries independently there. This stop costs O(k^alpha log³(2+k)) for that node including its answers. This is much smaller than q_v*k² when many edge combinations share few tails. It needs no new vertex slots or memory across queries.
3. Otherwise, if the padded actual needed size N'_v is at most beta*k, eliminate to that actual set and restart a fresh macro run on it, rebuilding its dyadic labels but retaining global original edge IDs. This costs O(k^alpha log³(2+k)) for the trim before the child macro work. (Can also apply this restart in place of step 2 when appropriate.)
4. Otherwise refine one level into occupied children. Every node with q_v<=c*k has r_v<=3q_v+2<=5q_v for q_v>=1 and padded r_v<=10q_v<=beta*k. Thus every node that refines has q_v>c*k; this remains true if extra direct stops or more small-anchor restarts are elected.

These rules preserve correctness because every removal leaves all tails needed by that node, and every query passes to exactly one branch. All restarts strictly shrink the universe by a constant factor. For q>=n³ one may bypass this entirely using the cubic full distance oracle plus output; q can exceed n³ because edges with distinct head choices can share one tail tuple.

## Worst-case potential

Let Phi(N,q)=N^alpha max(1,(q/N)^sigma). In a single macro run, the root is charged N^alpha. At level j>=1, the O(1) children per heavy parent imply a visited count
    O(min((N/k)^3, q/(c k))).
Compute their banks and optional trim or direct answers with O(k^alpha log³(2+N)) work per visit: a parent's block size is 2k, a fixed constant ratio. O(q) answers at k=1 are charged separately to output. Summing the block term gives O(c^(−sigma) Phi(N,q) log³(2+N)). To see it, balance the increasing term N³ k^(alpha−3) and decreasing term (q/c) k^(alpha−1) over k in [1,N]. Their crossing is k_*=sqrt(c N³/q). Both sides are geometric for dyadic k, and the clipped endpoints also obey the bound. Constants in this paragraph depend only on alpha, not beta or c.

Restart roots form an antichain in the macro run's complete 8-ary tree of labelled address triples. Therefore sum k_v³<=N³ (Kraft), and their assigned queries are disjoint, so sum q_v<=q. Since alpha−sigma=3(1−sigma), Hölder gives
    sum k_v^(alpha−sigma) q_v^sigma
        <= (sum k_v³)^(1−sigma)(sum q_v)^sigma
        <= N^(alpha−sigma) q^sigma.
The previous level-cost ledger gives sum k_v^alpha <= O(c^(−sigma) Phi(N,q)). Monotonicity of the two powers in Phi and N'_v<=beta k_v now give
    sum Phi(N'_v,q_v)
        <= beta^(alpha−sigma) sum [k_v^alpha + k_v^(alpha−sigma)q_v^sigma]
        <= O(beta^(alpha−sigma)(c^(−sigma)+1)) Phi(N,q).
Taking c=beta/10 and beta small makes this coefficient at most 1/2, since alpha−2sigma>0. Sum the work through the resulting restart tree by a geometric series, with the original maximum polylog factor common to all sizes. Query routing and computing actual anchor supports can scan each query once per visited level of each macro run containing it, O(q log²(2+n)) word operations overall; each macro has O(log n) levels and there are O(log n) restarts along any query path. Explicit answers incur O(q) output. For q<=n³, Phi(N,q)>=q up to padding constants. All storage can be freed after a subtree returns; this memo does not claim a new online-oracle space bound.

## Concrete gains, limits, and related results

Without restarts, optimizing a uniform stopping depth and dense queries on the entire active blocks crosses at q_v≈k^(alpha−2) and gives N^alpha max(1,q/N^(alpha−2))^((3−alpha)/(5−alpha)) up to logs. Without either stopping or restarting, building only occupied full-depth dyadic states gives about N^alpha max(1,q)^(1−alpha/3) up to logs. For q=n^x with 1<=x<3 the new exponent is strictly smaller than both: it interpolates between (x,time-exponent)=(1,alpha) and (3,3) rather than the respective earlier equal-exponent start at alpha−2 or 0. Compared with the single-trim no-restart forecast starting at alpha/3, it likewise starts later and improves every x in [1,3). At x=3 every bound meets the full-output baseline. Example of actual needed-size adaptivity: any number of edge-failure combinations on the same three tails can be answered after one trim to constant size, in Õ(n^alpha)+O(q), even if the failed original edges themselves are all different across the batch. More generally observed per-stop costs are q_v*r_v² rather than q_v³. Without restarting, an exact optimal policy for the chosen cost estimators on a fixed occupied trie could use bottom-up min(stop using parent graph; stop after trim; refine with computed child costs); the theorem above instead proves a universal rate with recursive restart and does not claim an optimum policy over arbitrary graph oracles.

[Harada–Terao, arXiv:2611.29061v1, Lemmas 13–14 and §4](https://arxiv.org/html/2611.29061v1) build all states, and announce cubic 3FRP; they do not state this supplied-batch parameter frontier in v1. The dyadic decomposition and sparsified first tags are explicitly theirs. [Vassilevska Williams–Woldeghebriel–Xu, FOCS 2022](https://ieee-focs.org/FOCS-2022-Papers/pdfs/FOCS2022-4Bu7jGV9xIcveUWYj3oWoi/551900a907/551900a907.pdf) use separate shortest-path interval handling and bounded-weight algebraic methods for two failures; their Theorem 6 conditional lower bound concerns combinatorial data structures on unweighted directed input, not this approach importing arithmetic matrix products. [Alon–Chechik–Cohen, ICALP 2019 §3](https://drops.dagstuhl.de/storage/00lipics/lipics-vol132-icalp2019/LIPIcs.ICALP.2019.12/LIPIcs.ICALP.2019.12.pdf) derandomize multi-failure query-independent arbitrary-endpoint oracles using hop intervals, a different output/query regime. The offline dynamic oracle used by [Chi–Duan–Wang–Xie, ICALP 2025](https://drops.dagstuhl.de/storage/00lipics/lipics-vol334-icalp2025/html/LIPIcs.ICALP.2025.57/LIPIcs.ICALP.2025.57.html) is undirected. No matching supplied-batch result found in these primary references, but no priority claim. Harada–Terao §4 also already announces two-fault fixed-terminal replacement paths in APSP time. That announcement does not provide the supplied three-failure batch algorithm. The newly checked lever is the restart bound on arbitrary real weights, not a claim that offline divide-and-conquer in general is new.

## Independent exact controls

python check.py checked 7,312 requested distances including 430 unreachable, 2,927 negative, 2,076 repeated-tail, 1,893 zero-fault, and 2,965 with a failed arc meeting a terminal. It executes actual dyadic grouping and compressed relabellings (231 restart events, 85 direct trims and 3,935 refinements), using sequential one-vertex tag updates to verify the shortcut semantics independently of the accelerated imported batch. Toy thresholds are deliberately larger to exercise the restart mechanism on small graphs. The comparison answers use independent Bellman–Ford with each actual edge removed. An independently reseeded replay added 8,825 exact queries, including 280 actual restarts, 71 direct trims, 4,935 refinements and 3,905 negative-weight answers. These are exact distance tests, not runtime or kernel verification.

The optional direct-stop arithmetic q_v*r_v²<=k^alpha can be implemented using fixed rational alpha and capped integer powering (the cited alpha is rational); it may also be omitted or replaced by a conservative cheaper test without changing the worst-case proof. No floor or exponentiation of any input real weight is used.

The same proof extends to each fixed f>=3: replace three slots by f, keep f+1 first-edge tags, and use log^f masks. Replace sigma by (f−alpha)/(f−1), since the balance is then between (N/k)^f and q/(c k), Kraft uses sum k_v^f<=N^f, and alpha−sigma=f(1−sigma). Actual anchor count is at most f q_v+2, so choose c=beta/(2(f+2)); contraction still follows from alpha−2sigma>0. This yields Õ(n^alpha max(1,(q/n)^((f−alpha)/(f−1)))+q), capped by the full O(n^f+q) route, with constants for fixed f. The controls here use f=3 only.
